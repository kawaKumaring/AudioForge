# 저장 원칙 변경 — 2026-10-14

사용자 지시: 개발 도구 내부에는 코드만 두며, 불러올 대사·설정·생성 기록은 음원을 만든 위치에 함께 있어야 한다. 결과 폴더를 지우면 기록도 함께 사라져야 한다. 내부에 시험·사용자 정보가 불필요하게 쌓이면 안 된다.

다음 구현은 결과 파일과 그 폴더의 기록을 한 소유 단위로 묶어 불러오기 통로를 통합해야 한다. 내부 색인이 삭제된 음원의 대사를 되살려서는 안 된다. 결과가 없는 편집은 메모리에만 두거나 사용자가 지정한 작업 폴더에 명시 저장해야 한다. 사용자에게 코드 밖 결과 저장 경로를 요청했다. 결과 폴더 확정 전 임의 위치로 옮기지 않는다.

기존 자료는 확인 없이 삭제하지 않는다. 사용자 자료 내용은 이 조사에서 열지 않았다. 설정 저장 관련 검사 9건 통과. 앱 실행·생성은 하지 않았다.
