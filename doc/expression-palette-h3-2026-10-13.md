# 감정 아이콘 도구와 H3 연기 비교

## 카드 화면

생성 카드 머리의 ‘감정’ 단추가 이동 가능한 작은 도구창을 연다. 모달·배경 덮개·초점 잠금 없이 대사를 계속 입력할 수 있다. 제목을 드래그하거나 키보드 화살표로 이동하고, 닫기 전까지 카드 화면에 남는다. 다른 작업실로 이동한 뒤의 창 위치·열림 복원은 이번 범위가 아니다.

대사 입력칸을 선택한 뒤 감정 아이콘을 누르면 커서 위치에 표시를 넣는다. 선택한 대사는 삭제하지 않는다. 대사 안에는 아이콘이 보이고 저장·복사에는 기존 합성 문법이 남는다. 표시는 기쁨·슬픔·분노·두려움·경멸·놀람·기본 말투·속삭임·0.7초 쉼이다. 기본 말투는 H3 calm과 같은 기능으로 주장하지 않으며, 경멸도 H3 disgusted와 동일하다고 주장하지 않는다.

아이콘과 도구 버튼은 같은 제목·설명의 공용 방식인 title 툴팁을 쓴다. 생성 중에는 대사와 표시 삽입을 막는다. 감정을 지원하지 않는 목소리에서는 생성 시작을 화면과 요청 함수 모두 차단한다. H3는 카드 엔진에 연결하지 않았으며, 웃음·호흡도 동작하는 버튼으로 제시하지 않는다.

기존 문법은 줄 중간의 첫 감정 태그를 앞 대사에도 적용한다. 아이콘을 중간에 넣은 요청본에는 초기 말투를 먼저 명시해 앞 대사가 새 감정에 덮이지 않게 했다. 저장된 원문은 그대로다. 엔진의 실제 감정 효과·발음·인물 닮음을 보장하지 않는다.

## 확인 범위

- 순수 규칙 4건: 저장 왕복, 이스케이프 보존, 미지원 차단, 실제 합성 문법에서 원문과 700ms 쉼 보존.
- 숨긴 검사 브라우저 15건: 커서 삽입, 선택 원문 보존, 도구 유지와 배경 입력, 다른 카드 전환, 복원, 드래그·키보드 이동, 좁은 창, 되돌리기, 복사·안전한 붙여넣기, 생성 중 차단.
- 렌더러 타입 검사 통과. 화면 캡처·앱 실행·전체 검사·카드 음성 생성은 하지 않았다.

## H3 연기 시험

앞선 30초 시험과 같은 장문·참조 A·seed 2024를 사용한다. 글을 원문 위치로 여덟 구간으로 나누고 이어 붙인 글이 원문과 완전히 같은지 확인한다. 감정 순서는 기쁨·슬픔·분노·두려움·혐오·놀람·차분함·속삭임이다. 가벼운 웃음·한숨·호흡·웃음과 약 0.7초 쉼도 요청한다.

Speech 2.8의 감정 값, 비언어 태그, 쉼 표시는 H3 문법이 아니다. H3에서는 한국어 대사를 `<d>[Korean] … </d>`로 감싸고 밖에 자연어 연기 설명을 둔다. 말할 시간 확보를 위해 이번 요청 길이는 40초다. 이전 30초 결과와 시간 조건이 같지 않아 순수한 속도·품질 차이로 판정하지 않는다. 여러 감정과 발성을 한 번에 요청하므로 원인 분리 실험도 아니다.

현재 생성 진행 중. 시작 뒤 ComfyUI 경합이 발견되어 사용자의 종료 승인 후 해당 서버만 종료했다. 기록에 각 단계와 자원 상태를 남긴다. 결과 파일·청취 링크·최종 관측은 생성 완료 후 추가한다. 감정·발음·참조 목소리 유지·발성·쉼 길이는 청취 판정 전이다.
