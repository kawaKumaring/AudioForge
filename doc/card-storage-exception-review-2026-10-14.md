# 카드 저장 예외 검수 보완

작업 불러오기 화면은 실제 앱 MCP로 합성 기록 18개를 확인했다. 카드형 목록, 내용 보기, 두 창 크기에서 가로 넘침 없음, 화면 오류 0건을 확인했다. 사용자 자료는 열지 않았다. 앞 단계 커밋은 ef89de8이다.

저장 통로의 Promise 예외가 저장 중 상태를 남기던 경로를 실패 상태로 바꾸었다. 두 통로가 모두 끝날 때까지 기다려 뒤 저장과 겹치지 않는다. 읽기 실패 이후 창 종료 저장도 차단했다. 재시도 읽기 실패는 미처리 예외로 올리지 않고 실패 상태를 유지한다. 저장 작업 삭제 요청도 저장 대기열에 등록한다.

관련 저장 검사 15건과 렌더러 타입 검사를 통과했다. 새 음성 생성과 전체 검사는 하지 않았다.

남은 구조 제한: 현재 작업·보관함 두 파일을 한 번에 확정하는 거래는 아직 없다. 파일 삭제와 여러 메타데이터 갱신도 전체 거래가 아니므로 OS 오류 시 부분 완료 가능성이 있다. 후속 구현에서 복구 절차가 필요하다. 기존 session/H3 기록 제거는 다른 카드가 공유할 수 있어 자동 승인 검토에서 거절되어 적용하지 않았다.
