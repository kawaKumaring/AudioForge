# 참조 선택·연결 보존 개선 (2026-10-11)

사용자 지시: 기존 목소리·발음 보호, 구현 후 관련 검사 일괄 실행.

## 구현
- Qwen 생성 조각·진단 원음·속도 처리·결합 중간물을 FLOAT로 보존한다. ICL 절단은 입력 형식을 유지한다.
- 최종 마감에서만 피크 0.97 초과를 전체 동일 배율로 줄인다. 압축/음높이/EQ 변경이 아니다. final_peak_gain 기록.
- 카드의 선택적 음량 맞추기는 20ms 창의 에너지로 계산한다. -60dBFS 및 최고 창 대비 -35dB 문턱을 함께 쓰고 프레임 길이로 가중한다. 음성 인식이나 VAD가 아니므로 음악/잡음도 포함될 수 있다. 증폭/감쇠 한도 유지.
- 내부 독립 조각 경계의 2ms가 전부 -60dBFS 이하인 경우만 영점으로 완만히 연결한다. 높은 진폭 경계는 그대로 두며 적용 여부를 기록한다. 삭제/겹침/추가 무음 없음. 기존 줄·문단·명시 쉼 계약은 유지한다. 작은 호흡도 변할 가능성은 있으므로 완전한 청각적 무손상을 주장하지 않는다.
- 자동 참조는 기존 무음 경계 후보에서 발화량 최고치의 95% 이상을 먼저 추린 뒤 클리핑이 적은 후보를 우선한다. 최대 3개 후보와 선정 정책을 반환한다. 저장된 참조/수동 선택을 바꾸지 않는다. 잡음·울림·단일 화자 판별은 구현하지 않았다.

## 의도적으로 유지
- 음량 일괄 평탄화, 음높이 수정, 재학습 없음.
- 생성 음성에 있는 쉼과 사용자가 지정한 추가 쉼은 삭제하지 않는다.
- 참조 억양 모드와 seed 정책을 자동 전환하지 않는다.
- 사용자의 기존 파일은 읽기/수정하지 않는다. 검사는 합성 신호만 사용한다.

## 검증
구현 후 관련 검사 215건 통과(신규 보존 검사 9건 포함). 최초 묶음은 기존 참조 확정 검사에서 실제 받아쓰기 경로를 호출해 멈춰 중단했다. 해당 확정 검사 2건을 제외한 묶음을 완료했다. 실행 도구의 기통과 항목 식별 처리로 일부 기존 검사가 다시 실행됐다. 실패 0·건너뜀 0(제외 2건은 별도). 실제 TTS 생성/앱/청취 미실행. 로그: master/_local/테스트/기록/speech-join-reference-20261011-remaining.txt.

참조 후보 선정의 95%·에너지 문턱은 보수적인 초기 규칙이며, 청취로 최적값을 입증하지 않았다. 목소리 유사도 향상을 확정하지 않는다. 기존 저장 음성과 참조를 재작성하지 않으며 새 생성·새 자동 추천에 적용한다. 낭독 캐시 재사용본은 그대로다.
