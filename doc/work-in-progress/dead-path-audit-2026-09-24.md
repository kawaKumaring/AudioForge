# 전면 감사 — "만들었지만 닿지 않는 것" 을 찾는다 (2026-09-24)

## 왜 했나
오늘 찾은 결함이 **전부 우연히 드러났다.**
- Kokoro 합성 엔진이 목소리를 안 넘겨 **모든 언어에서 죽어 있었다**
- "한/일/중/영 지원" 이라 적혀 있었으나 **넷 중 셋이 거짓**
- 배경음 걷어내기를 만들고 검사까지 했는데 **화면에 연결하지 않아 영향이 0**
- 반복 제거가 **되풀이가 없어도 "고쳤다" 고 세고** 있었다
- 검사 하나가 고정 경로 때문에 **터지지도 않고 조용히 건너뛰고** 있었다

우연에 기대면 나머지는 계속 숨어 있다. **같은 눈으로 전면을 훑었다.**

## 어떻게
여섯 가지 눈으로 병렬 수색 → 발견마다 **두 명이 반박 시도** → 반박을 견딘 것만 남김.
반박자에게는 "확신이 서지 않으면 반박 쪽으로 기울여라" 를 지시했다 —
**잘못된 보고가 놓친 것보다 나쁘다.**

발견 24건 · 반박을 전부 견딤 15건 · 절반만 반박 8건.

---

## 고친 것 넷 (직접 재확인한 뒤)

### A-1 ★'끝 잘림 의심' 꼬리표가 **한 번도 뜬 적이 없다**
파이썬은 `emit("result", tracks=..., metadata=meta)` 로 metadata 를 **tracks 의 형제**로
보내는데, 화면은 `tracks[0].metadata` 라는 **트랙 안쪽**을 읽고 있었다.
트랙에는 그 열쇠가 아예 없다 → 값이 늘 undefined → 판정 늘 false → **꼬리표 영영 안 뜸.**
받는 인자가 `any` 라 타입검사도 잡지 못했다.

**★어제 제가 "재기·판정·표시가 다 있다" 고 한 말이 틀렸다.** 표시는 닿지 않는 자리를 읽고 있었다.

고침: 꺼내는 자리를 `tailResidualOf()` 순수 함수로 빼고 검사 8건으로 못 박았다.
검사에는 **파이썬이 실제로 보내는 모양**과 **예전의 잘못된 추측 모양**을 둘 다 넣었다.

### A-2 화면이 보여 주는 조각 이름이 윈도에서 만들 수 없는 이름
`splitPieces.ts` 와 `split_markers.py` 에 **똑같이** `'\/:*?"<>|'` 라 적혀 있는데
**읽히는 값이 달랐다.** JS 는 `\/` 를 `/` 한 글자로 읽어 역슬래시가 빠지고(8글자),
파이썬은 모르는 표기라 그대로 둔다(9글자).

실측: 이름 `AC\DC` → 화면 `AC\DC` · 저장 `ACDC`.
역슬래시는 윈도 파일 이름에 못 쓰므로 **파이썬이 맞고 화면이 틀렸다.**

덤으로 찾은 것: 파이썬 표기가 `SyntaxWarning: "\/" is an invalid escape sequence` 를 낸다 —
**앞으로의 파이썬에서 깨질 표기**다. 감사가 못 짚은 위험이다.

고침: 양쪽 다 **눈에 보이게** 적었다. 미러 검사에 역슬래시 예제를 **양쪽 다** 넣었다
(없어서 파리티 검사가 이 글자를 비워 두고 있었다).

### A-5 게이트가 '조용히 건너뛴 검사' 를 통과에 섞었다
unittest 는 **전부 건너뛰어도** `Ran N tests` + `OK (skipped=N)` + exit 0 을 낸다.
우리 집계는 `Ran N` 과 `OK` 만 보고 **건너뜀을 통과로 합산**했다.

실제로 이 기계에서 **4건이 돌지 않고 있었다.**

고침: 건너뜀을 뽑아 파일별로 찍고 요약에 따로 적는다.
저장소 원칙이 이미 "건너뛴 사실을 요약에 남긴다" 이므로 규칙 변경이 아니라 **이행**이다.

### A-6 청취 승인 자산 검사가 없어진 고정 경로를 보고 있었다
`test_macro_gain.py` 에 `apps/development/AudioForge/...` 절대경로가 박혀 있었는데
저장소가 `apps/master/AudioForge` 로 옮겨져 그 폴더가 사라졌다. **자산은 새 자리에 그대로 있다.**

이게 왜 중요한가: macro gain 보정 기준값이 **실제 청취 판정과 맞는지 보는 유일한 검사**다.
지어낸 시험 25건은 여유가 넉넉해 규약이 틀어져도 전부 초록이다.

고침: 저장소가 이미 가진 해석기(`local_assets`)를 쓴다.
그리고 **경로 깨짐과 환경 없음을 갈랐다** — soundfile 이 없으면 정직하게 건너뛰되
그 사실이 게이트 요약에 드러난다.
실측: 게이트 파이썬 1건 건너뜀 · **앱 파이썬 25건 전부 돈다**(예전에는 조용히 건너뜀).

# 덧붙임 — 감사를 따라가다 **주력 엔진이 죽어 있는 것**을 찾았다 (같은 날)

## 감사 항목(B-2)을 확인하러 갔다가
감사의 주장은 "일본어가 반드시 GPT-SoVITS 로 가는데 그 venv 에 일본어 부품이 없다" 였다.
확인하러 실행 경로를 따라가니 **그 전에 이미 죽어 있었다.**

## ★폴더 이동의 세 번째·네 번째 여파
아침에 이동을 복구할 때 두 가지를 고쳤다(git 링크 · externals 링크).
**두 개를 더 놓쳤다.**

1. **`runtime.json` 이 옛 절대경로를 적어 두고 있었다.**
   설치하던 때의 절대경로다. 저장소를 옮기자 죽었고, venv 는 새 자리에 멀쩡히 있는데도
   **GPT-SoVITS 가 통째로 닿지 않았다.**

2. **그 venv 의 `pyvenv.cfg` 도 옛 경로를 가리키고 있었다.**
   바탕 파이썬이 앱 소유(옮긴 폴더 안)라 같이 죽었다.
   `python.exe` 를 부르면 `No Python at '...development\AudioForge\...'` 가 났다.

## 왜 이게 특히 나쁜가
**조용히 죽는다.** 엔진 고르기가 예외를 잡아 다른 엔진으로 내려보내므로,
사용자는 **주력 엔진이 죽은 줄 모른 채 다른 목소리를 듣는다.**
오늘 만든 폴백(한국어 piper · 일본어 Kokoro)이 아니었다면 아예 실패했을 것이다.

## 고친 것

**수리(사용자 환경)**
- `pyvenv.cfg` 의 경로 4군데를 새 자리로. 원본은 `pyvenv.cfg.bak-2026-09-24` 로 남겼다.
- 그 venv 에 `pyopenjtalk-plus` 설치 — **격리된 venv** 라 공용 파이썬보다 위험이 낮다.
  꾸러미 114 → 117, 더해지기만 했다. 실측: `こんにちは` → `k o N n i ch i w a`.
  **이제 주력 엔진으로 일본어가 된다.**

**소스(다음 이동에도 견디게)**
- `app_runtime.relocate_recorded` — 적어 둔 자리가 죽었으면 **지금 저장소의 externals
  아래에서 같은 구조를 찾는다.** 찾지 못하면 적어 둔 것을 그대로 돌려준다
  (없는 것을 지어내지 않는다). 기록을 고쳐 쓰지는 않는다 — 그건 설치기의 몫이다. 검사 5건.
- **B-2 원인 자체** — `GPTSoVITSEngine.load(lang)` 가 언어를 받아 **그 언어를 정말 할 수
  있는지** 본다. 못 하면 식별 코드와 사유로 실패해 엔진 고르기가 다른 엔진으로 보낼 수 있다.
  예전에는 venv 파일만 봐서 폴백이 **영영 걸리지 않았고**, 실제 실패는 한참 뒤 다리에서 났다.
  Kokoro·piper 는 같은 날 이 구멍을 메웠는데 여기만 남아 있었다.
  조사 결과는 기억해 두어 느린 조사를 되풀이하지 않는다.
  조사 자체가 실패하면 **막지 않는다** — 다리가 제 사유로 실패하게 둔다.

## 다른 venv 넷은 멀쩡하다
`asr_ct2_venv` · `diarization_venv` · `gptsovits_venv` · `qwen3_tts_venv` 전부 정상.
바탕 파이썬이 **옮긴 폴더 밖**(ComfyUI 쪽)이라 경로가 움직이지 않았다.
피해는 앱 소유 파이썬을 쓰는 한 곳뿐이었다.

## 남은 흠 (해롭지 않음)
venv `Scripts/*.exe` 껍데기 안에 옛 경로가 박혀 있다. 우리는 그것들을 이름으로 부르지 않고
`python.exe -c` / `-m` 로만 쓰므로 영향이 없다. `.pyc` 캐시의 경로도 무해하다.

## 검증

# 덧붙임 3 — 저장 실패가 조용히 사라지던 것 (B-1)

## 무엇이 잘못됐나
`window.api.settings.set` 은 실패를 **예외로 던지지 않고 `{ok:false, code}` 를 돌려준다.**
그래서 `void ...set(...)` 로 부르면 실패가 통째로 사라진다.

설정 파일이 한 번 깨지면(`SETTINGS_CORRUPT`) 그때부터 모든 쓰기가 거부되는데,
**작업실 회차·채택·대사 수정·전사 교정이 하나도 저장되지 않고 화면은 아무 말도 안 한다.**
앱을 닫는 순간 전부 잃는다.

## ★한 번 고친 사고가 세 곳에 남아 있었다
같은 사고를 **2026-09-09 관리자 검수**에서 겪고 `useWorkDraft` 에서 고쳤다.
주석에 사연까지 적혀 있다. 그런데 네 자리가 옛 방식 그대로였다
(작업실 둘 · 대사 수정 · 전사 교정).

**사람이 기억으로 막을 수 없다.**

## 고친 것
- `src/shared/saveSetting.ts` — 응답을 버리지 않는 **단일 통로**.
  던지지 않되(저장 실패가 화면을 무너뜨리면 안 된다) **조용히 넘기지도 않는다**
  — 부르는 쪽이 반드시 결과를 받는다.
- 보일 문구는 **무엇을 잃는지 먼저** 말한다:
  "설정 파일이 손상돼 있습니다 — 지금 고친 내용이 저장되지 않았습니다. 앱을 닫으면 사라집니다."
- 네 자리를 전부 그 통로로 옮기고 각 화면의 알림 자리에 사유를 띄운다.

## ★같은 것이 다시 들어오지 못하게
`src/shared/saveSetting.test.ts` 가 **소스 전체를 훑어** `void ...settings.set(` 표기를
금지한다. 붙이자마자 네 자리를 전부 잡았고, 고친 뒤 통과한다.
주석 줄은 빼서 사연을 적어 둔 곳이 걸리지 않게 했다.

이것이 감사가 말한 **뿌리 6(응답을 버린다)** 을 닫는 방법이다 —
고치는 것만으로는 세 번째·네 번째가 또 생긴다.

## 검증
게이트 **통과 9 · 실패 0** (파이썬 2,937건 · 138파일 · 건너뜀 3건).

# 덧붙임 4 — 속도를 버리던 엔진과, 오프라인 약속을 어기던 자리 (B-5·B-3)

## B-5 piper 가 속도를 받아서 버리고, 기록에는 썼다고 남았다
★**어제 내가 넣은 엔진의 빚이다.**
`synthesize_segment(..., speed, ...)` 가 speed 를 한 번도 쓰지 않았다.
다른 세 엔진은 전부 넘긴다. 못 넘기는 것도 아니었다 — piper 에 길이 배수 설정이 있다.

사용자에게 보이는 것: piper 로 떨어지면 **속도 조절이 아무 일도 안 한다**(화면은 늘 활성).
게다가 **재현 기록에 요청값이 적용값처럼 남는다.**

고침: 길이 배수로 넘긴다(값이 클수록 느려지므로 뒤집는다).
실측 — 속도 0.8 → **4.17초** · 1.0 → **3.51초** · 1.3 → **2.86초**.
못 넘기는 환경이면 기본 속도로 내되 터뜨리지 않는다.

## B-3 트랙의 '가사' 가 고른 설정을 무시하고, 오프라인 약속도 어겼다

### 고른 설정이 안 갔다
트랙 처리 설정에 `whisperModel`·`whisperLang`·`asrSeparate` 가 **아예 없었다.**
`translateModel` 만 싣는 비대칭이라 의도가 아니라 누락이다.
→ Small 을 골랐든 언어를 한국어로 강제했든 **전부 무시되고 늘 large-v3·자동감지**로 돌았다.
사용자는 자기 설정으로 돈 줄 안다.

고침: 화면 → 통신 → 파이썬까지 셋을 실어 보낸다.

### 오프라인 약속을 어겼다
`separate.py` 가 whisper 를 **두 번 직접** 불렀다(해석기를 거치지 않고).
해석기는 `download_root` 를 명시해 앱 모델 폴더만 보게 하는데, 직접 부르면
**`~/.cache` 를 뒤지고 없으면 내려받는다.**

게다가 그중 하나는 `"base"` — **화면 목록에도 앱 자산에도 없는 다섯 번째 모델**이고,
'다시 번역' 의 주 경로였다. 오프라인에서는 받을 길이 없다.

고침: 둘 다 해석기 경유. 언어 감지는 앱이 실제로 가진 `small` 로 바꿨다.
**이 기계에 캐시가 있어 가려져 있었을 뿐이다** — 새 PC·오프라인에서 드러난다.

### ★이 위반을 게이트가 통과시킨 이유
`test_whisper_resolution` 이 `transcribe_worker.py` **한 파일만** 소스 검사했다.
오프라인 약속은 한 파일의 약속이 아니다.
→ **저장소의 파이썬 전체**에서 해석기 밖 직접 호출을 금지하도록 넓혔다.
해석기가 사는 파일만 예외다.
