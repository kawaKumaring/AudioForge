# 알아듣기 모델 시험 기록 — 쓸 수 없다고 판정한 것들 (2026-09-21)

무엇을 받아 보았고, 왜 쓰지 않기로 했는지 남긴다.
**받은 파일은 격리 폴더로 옮겼다** — 나중에 지우기 위해서다.

## 어떻게 쟀나

사용자가 가사 파일을 준비해 주어 **정답지로 잴 수 있게 됐다.**
그 전까지는 '모델 자신의 확신도' 같은 대리 지표로만 견주었다.

- 재료: 일본 노래 한 곡(4분 10초)의 **주 보컬**(반주 분리 → 주 보컬/화음 분리를 거친 것)
- 정답지: 가사 파일의 일본어 원문 **419자**
- 자: 글자 단위 오류율(CER). 공백·문장부호는 틀린 것으로 세지 않는다.
- 도구: `python/dub_eval.py`, `python/asr_compare.py`

★**노래는 알아듣기의 가장 어려운 경우다.** 여기 숫자를 대화 영상의 성능으로 읽으면 안 된다.

## 결과

| 모델 | 정확도 | 판정 |
|---|---|---|
| **whisper large-v3** (원래 있던 것) | **73.1%** | **쓴다** |
| whisper large-v3-turbo | 64.2% | 격리 |
| whisper large-v2 | 61.3% | 격리 |
| Qwen3-ASR-1.7B | 55.9% | 격리 |
| whisper medium | — | 받지 않음(앱의 오프라인 장치가 막았다) |

설정 쪽도 전부 재 보았다 — 입력(보컬 전체/주 보컬), beam 5, 앞 문맥 켜기, 노래라고 미리 알려 주기.
**71.7 ~ 75.3% 안에서만 움직였다.** 설정으로는 올라가지 않는다.

## 왜 벤치마크와 반대로 나왔나

Qwen3-ASR 은 2026 일본어 벤치마크에서 **1위**였다(글자 오류율 0.140, whisper-large-v3-turbo 0.184).
그런데 우리 시험에서는 꼴찌였다.

**그 벤치마크는 '대화' 로 잰 것이다.** 노래는 다른 문제다.
위스퍼는 웹의 온갖 소리로 학습해 노래에 강하고, 대화 전용으로 다듬은 모델은 노래에서 무너진다.

→ **순위표는 재료가 다르면 옮겨오지 않는다.** 이 기록의 가장 중요한 교훈이다.

## 찾아보고 쓰지 않기로 한 것들 (받지 않음)

- **일본어 가사 전용 모델은 공개된 것이 없다.**
  베트남어는 있다(VietLyrics 가 small·medium·large-v2 공개). 일본어는 없다.
  허깅페이스의 일본어 알아듣기 목록도 직접 보았으나 작은 wav2vec2 계열뿐이다.
- **VocalParse**(2026 노래 전사 최신 연구, 코드·가중치 공개) — **중국어 전용**이다.
  저자들이 다른 언어는 구조를 더 손봐야 한다고 적었고, 게다가 Qwen3-ASR 기반인데
  그것은 위에서 잰 대로 우리 재료에서 나빴다.
- **kotoba-whisper** — 검색 요약은 좋다고 했으나 같은 벤치마크 표에서 **꼴찌(0.495)** 였다.
- **LyricWhiz 방식**(위스퍼를 3~5번 돌려 LLM 이 고르기) — 받을 것은 없다.
  다만 논문 자신의 표에서 이득이 **0.2~3.9%포인트**다. 아직 만들지 않았다.

## 아직 답하지 않은 것

- **대화 영상으로 재 보지 않았다.** 지금 숫자는 전부 노래다.
  대화는 훨씬 높게 나올 것이고, 모델 선택의 답도 달라질 수 있다.
- 지금 73.1%는 논문들이 보고하는 가사 전사 최신 수준(오류율 25~50%) 언저리다.

## 함께 알게 된 것 (따로 볼 항목)

- **모델의 확신도는 정확도를 예측하지 못했다.**
  '확신 낮은 줄 0%' 로 가장 좋아 보인 설정의 실제 정확도가 그대로였다.
  정답지가 없었다면 그것을 개선으로 보고했을 것이다.
  → **알아듣기 판단은 정답지 없이 하지 않는다.**
- ComfyUI 의 XTTS 노드가 `.pth` 로 자기 폴더를 **이 파이썬을 쓰는 모든 프로세스**의 경로에 얹어 둔다.
  흔한 이름(`model`)을 부르는 꾸러미가 엉뚱한 것을 잡는다. AudioForge 워커도 같은 파이썬을 쓴다.
- 앱의 오프라인 장치가 **모르는 위스퍼 모델의 조용한 내려받기를 막았다.** 제대로 일했다.
- 게이트가 **새 모델을 이용 조건 목록에 등록하지 않은 것**을 잡아냈다.
