# 생성 카드 화면 — 기능 대응표 (2026-09-27 갱신)

Codex 의 `synthesis-card-ux-review-2026-09-27.md` 대응표를 이어받아,
**이번 확인으로 달라진 줄만** 갱신했다. 이름이나 단추가 있다는 이유로 연결 완료로 적지 않는다.

판정은 넷이다.
- **연결 완료** — 새 화면에서 실제로 되고, 이번에 확인했다.
- **연결만 필요** — 엔진·규칙은 있고 화면에서 부르면 된다.
- **새 설계 필요** — 없는 것을 만들어야 한다.
- **후속** — 이번 범위 밖으로 남긴다.

## 이번에 판정이 바뀐 줄

**기본 목소리 저장·복원** — 미해결 → **연결 완료(실제 앱 확인)**
Codex 가 재현했던 `builtin → none`, `takeVoice true → false`, `appliedReference → null` 이
모두 사라졌다. Codex 의 재현 스크립트를 그대로 돌려 `builtin → builtin`,
`true → true`, 참조 구간 보존을 확인했고, **진짜 앱을 두 번 띄워** 기본 목소리로 실제 생성
(piper) → 종료 → 재시작 → 명시 복원까지 14건 통과했다.

**생성 당시 기록 고정** — 미해결 → **연결 완료**
요청 시작 때 `voiceSnapshot` 을 job 에 굳히고, 결과는 그 요청의 것일 때만 붙는다.
수정 전 판정은 `shared/synthesisCardJob` 하나가 소유한다(카드·생성본 목록·최종 구성이 같은 잣대).

**최종 연결 실패 복구** — 없음 → **연결 완료(실제 앱 확인)**
이어 듣기·저장이 실패하면 최종 음성 줄에 사유와 **다시 시도**가 뜬다.
실패해도 카드·대사·채택은 그대로다(실제 앱 6건).

**카드 생성 실패 복구** — 없음 → **연결했으나 확인 실패**
카드 줄에 사유와 **다시 생성**을 붙였고, 본체 오류 이벤트도 그 카드로 보낸다.
★그러나 **실제 앱에서 발화시키지 못했다** — 아래 '열린 문제' 참고.

  생성본 목록(팝업)·재생·채택·폴더·당시 대사 · 카드 드래그/Alt+↑↓ · 삭제 되돌리기 ·
  카드 복제 · 속도·음높이(범위 보정 표시) · 최종 이어 듣기·저장 · 최종 구성 보기
- **연결만 필요**: 연결부만 듣기(자리만 있음) · 말끝 잔량 경고 표시(엔진 메타는 있음)
- **새 설계 필요**: 배역 공유(같은 인물을 여러 카드가 공유) · 전체 생성 대기열 ·
  긴 대본의 분할 단위 · 참조 전사·목표 길이·말끝 다듬기의 카드별 선택
- **후속**: 감정·쉼·대본 표기(보류 중) · 옛 작업 가져오기(다음 단계)

## 열린 문제 — 이번에 못 고친 것

### 1. 생성 시작 거절이 화면에 뜨지 않는다 (내 변경 이전부터)

실제 앱에서 `audio:process` 를 거절하도록 바꾸고(거절되는 것은 확인했다:
`Error invoking remote method 'audio:process'`) 카드의 **생성**을 눌렀다.

결과: **카드 실패 표시도, 예전의 전역 알림도 뜨지 않았다.** 작업 상태도 비어 있었다.
`startCardGeneration` 은 거절을 잡아 사유 문자열을 돌려주게 되어 있고, 화면은 그 값을
받아 표시하게 되어 있다. 그 사이 어디선가 **삼켜지고 있다.**

- 내 변경(카드별 실패 표시) 때문이 아니다 — 같은 조건에서 **전역 알림도** 뜨지 않았다.
- 원인을 찾지 못했으므로 검사에서 통과로 적지 않았다
  (`test/e2e/card-recovery.e2e.mjs` 에 사유를 적고 그 시나리오를 뺐다).
- 사용자 영향: 시작이 거절되면 **아무 말 없이 아무 일도 일어나지 않는다.**

다음에 볼 곳: `generate()` → `startCardGeneration()` 의 반환 경로와 `alive.current`,
그리고 `beginIndependentWork/endIndependentWork` 가 상태를 되돌리는 순서.

### 2. 앱이 쓰는 파이썬 경로가 사라진 폴더를 가리킨다

`externals/env.json` 의 `python` 값이 `E:\ComfyUI\...` 인데 **그 폴더가 없다.**
실제 위치는 `E:\AI\ComfyUI_windows_portable_python3.12\python_embeded\python.exe` 로 보인다
(존재 확인, 3.12.10, 기본 목소리 목록도 정상 반환).

이 때문에 기본 목소리 목록이 비어 재시작 검사가 **건너뛰기**로 끝났다.
★지시에 따라 **파일을 고치지 않았다.** 이번 검사는 `AUDIOFORGE_PYTHON` 환경변수로만 우회했다.
`singing_python`·`singing_script`(Seed-VC 새 위치)는 정상이다.
