# CosyVoice3 연출 경로 흡수 — 2026-10-12

## 범위

기존 Qwen 자동 경로와 기본 목소리는 유지한다. 합성 카드의 참조 목소리에서 고급 옵션으로 CosyVoice3를 명시 선택한다. 낭독의 상주 경로는 이번 변경에 포함하지 않는다. 새 모델을 자동 기본값으로 삼지 않는다.

## 계약

- 원문과 엔진에 보낸 글/연출은 구분한다. 공식 instruct2와 같은 별도 지시 + 참조 특징 경로를 쓴다.
- 자동 다운로드와 외부 전송 없음. 한국어를 영어 정규화기로 바꾸는 공식 frontend 단계는 사용하지 않는다.
- 지원 감정만 명시 전달. 미지원 감정·내부 제어 토큰·누락 참조는 실패하며 Qwen으로 몰래 대체하지 않는다.
- 쉼표·마침표는 독립 생성으로 바꾸지 않는다. 같은 화자·감정의 일반 줄은 제한 범위에서 묶는다. 문단·명시적 쉼·감정/화자 변화는 보존.
- 자연 쉼의 길이는 보장하지 않는다. ♥/!의 지시는 요청일 뿐 청취 합격 표시가 아니다.
- 원본 참조는 읽기만 한다. 참조 캐시는 내용 지문으로 구분한다. 만든 음성은 전체 PCM 보존, 초과 레벨만 일정 계수로 낮춘다. 말끝은 기존 공용 보존 마감 사용.
- 모델 로딩/생성은 기존 Python 작업의 취소 트리에 속한다. 별도 상주 프로세스를 추가하지 않는다.
- 생성 스레드 실패·상한 도달은 미완성 파일을 발행하지 않는다. GPU 부족 시 CPU로 몰래 바꾸지 않는다.
- 요청 대사와 지시는 private 기록에, 공개 헤더에는 씨앗·참조 지문·모델 판·프레임 등만 남긴다.

## 검증 계획

구현 완료 후 관련 Python/카드/기호/저장 검사만 묶어 실행. 실제 모델 파일 지문과 오프라인 불러오기 확인. 기존 승인된 기준 참조 A/B를 읽기만 하고 같은 대사로 Qwen 자연스럽게 / Cosy 자연스럽게 / Cosy 기쁨 / Cosy 다정 비교 자료를 만든다. 원본 지문·실제 조건·완성 경로 보존. 생성 성공·자동 검사·사람 청취 판정은 구분한다.

관련 검사 결과와 실제 생성 결과는 작업을 마칠 때 이 문서에 추가한다. 아직 목소리 닮음·발음·감정·말끝 품질을 보장하지 않는다.


## 관련 검사와 실제 추론

관련 Python 검사 61개(기존 영향 경로 포함), 카드·기호·저장 관련 Node 검사 73개 통과. 렌더러 타입 검사 통과. 전체 게이트·전체 단위 검사는 하지 않았다. 실제 코드 오프라인 import 확인. 생성 음성이 비정상일 때 기존 결과를 보존하고, 정상일 때 모든 프레임과 참조 지문을 보존하는 계약 검사 포함.

실제 GPU 추론에서 A/B × 자연스럽게/기쁨/다정 6개 생성 성공. 첫 준비 중 numba 임시 파일 생성 대기를 확인했고, 테스트 프로세스의 TEMP/TMP/NUMBA_CACHE_DIR을 앱 테스트 폴더로 지정하여 해결. 공유 Python 패키지나 ComfyUI 설정은 변경하지 않았다. Qwen 기준과 상황극 비교 생성은 이어서 진행한다.

사용자 추가 요청: A/B/C 같은 상황극 대사 × 자연스럽게/분노/슬픔/명랑/낮고 부드럽게 15개. 마지막 조건은 '섹시'를 탐색하는 자유 지시이며 공식 지원·품질 보장을 뜻하지 않는다. 제품 감정 목록에 섹시 항목을 추가하지 않는다. 자유 지시 문자열은 해당 실험 프로세스에만 적용한다.


## 실제 생성에서 발견한 호환 결함과 보완

공유 transformers 4.57.6에서 공식 Qwen2Encoder의 단일 토큰 attention_mask가 이전 KV 길이를 포함하지 않았다. 현재 masking_utils는 부족한 길이를 0으로 패딩하므로 이전 대사 문맥이 가려졌다. 초기 Cosy 6개는 자동 전사에서 요청 대사와 크게 어긋났고, 정상 품질 비교 대상으로 쓰지 않도록 페이지와 기록에 표시했다. 상황극은 초기 자연/분노 2개까지만 만들어지고 나머지는 중단했다. 파일은 보존했다.

Cosy 인스턴스의 forward_one_step에만 이전 KV 길이 + 현재 토큰 전체의 마스크를 전달한다. 공유 transformers/torch 설치나 Qwen 구현은 변경하지 않는다. 작은 실제 Qwen2 디코더에서 캐시 생성과 전체 문맥 생성의 마지막 hidden state가 일치하는 검사 통과. 같은 A/대사/seed 보완 후 한 개는 요청 네 문장 그대로 전사되었다. 자동 전사 일치는 음색·감정·발음 품질의 청취 합격을 대신하지 않는다.

공식 저장소 관련 보고: https://github.com/QwenAudio/CosyVoice/issues/1446 . 이 보고 자체를 원인 확정 근거로 삼지 않고, 로컬 코드의 0 패딩과 보완 전후 실제 생성/전사 및 디코더 검사를 근거로 삼았다.
