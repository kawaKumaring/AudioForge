#  변환 단계 분리 관측 준비

새 생성은 마지막으로 미룬다는 사용자 지시를 유지한다. 이번에는 모델 추론·GPU 생성·다운로드 없이 관측 코드를 구현했다. 제품 기본 및 노래 경로 변경 없음.

python/speech_vc.py의 --diagnostics-dir는 기본 꺼짐이다. 지정한 새 폴더에만 로컬 중간 자료를 저장한다. 기존 폴더 거절. 자료는 음성·화자 정보를 담으므로 외부 전송·커밋 대상이 아니다.

기록: 입력과 참조의 지문, 실제 모델 파일 지문, seed/정밀도/단계/CFG, 리샘플링 후 입력·참조, 입력·참조 멜, 내용 특징, 화자 임베딩, 조각별 생성 멜, BigVGAN 마지막 선형 출력, 제한 후 파형. 배열은 npy, 통계·지문은 record.json.

출력 파일이 저장된 뒤에만 기록의 상태가 complete가 된다. 실패 시 recording으로 남아 불완전함을 드러낸다. 저장 실패는 숨기지 않는다. forward 관측 장치는 finally에서 해제하고 출력 신호를 바꾸지 않는다. 모델의 tanh/잘라내기 설정은 그대로 따른다.

검사: 기록 왕복·원본 배열 불변·이름/유효하지 않은 값/덮어쓰기 거절·출력/CPU 난수 상태 불변·실패 시 관측 해제·완료 지문 확인. 실제 생성의 중간 자료가 채워지는지는 아직 확인하지 않았다. 초기 검사 한 건은 검사에서 UTF-8을 지정하지 않아 실패했으며 검사 읽기만 수정했다.

최종 비교에서는 변환된 멜의 음성 복원과 승인된 기존 원음 멜의 복원 대조를 분리한다. 변환을 하지 않은 복원에서도 기계음이 나타나는지 확인해야 복원기 문제를 좁힐 수 있다. 이 비교는 아직 실행하지 않았다.
