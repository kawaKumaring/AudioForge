# 카드 GUI 후속 개선 — 2026-09-27

이번 작업은 기존 카드의 조작 흐름 개선이다. 옛 작업 가져오기는 구현하지 않았다.

## 실제 앱 변경

1. 참조 목소리 준비 실패 옆에 **다시 시도**를 제공한다. 기존 준비 경로를 다시 호출하며, 다른 카드나 대사·생성본·채택을 변경하지 않는다. 준비 중에는 버튼이 사라지고 작업 중에는 잠긴다.
2. **구간 확인**을 누르면 해당 카드의 고급 옵션에서 참조 설정을 펼치고 선택 칸으로 초점을 이동한다. 팝업을 여는 것만으로 구간·설정은 바뀌지 않는다.
3. 최종 음성 구성에서 생성본 선택으로 들어온 경우 **구성으로 돌아가기** 아이콘을 제공한다. 채택을 바꾼 뒤 같은 구성 목록에서 결과를 확인할 수 있다. 일반 카드에서 연 생성본 팝업에는 불필요한 돌아가기 버튼을 추가하지 않는다.
4. 개발 중/옛 버전 탭에 방향키·Home·End 이동, 선택된 탭만 Tab 순서에 포함, 탭과 작업 화면 연결을 적용했다. 작업 중 전환 잠금은 키보드에도 동일하다.

설명 문단은 추가하지 않았다. 저장 구조, 모델 실행, 감정 제어, 가져오기 변환은 변경하지 않았다.

## 상태 흐름

`준비 실패 → 다시 시도 → forgetCardReference → 기존 카드 준비 effect → prepareCardReference → 준비/실패 상태`

재시도 버튼에서 준비 IPC를 별도로 중복 호출하지 않는다. 실제 준비의 소유자는 기존 함수와 effect다.

`구간 확인 필요 → 설정 팝업(참조 펼침/초점) → 취소 또는 적용`

`최종 음성 구성 → 해당 생성본 → 채택 변경 → 구성으로 돌아가기 → 변경된 채택 표시`
