# 낭독·합성 결과·공용 재생 개선 인계

## 개발선 반영 범위
낭독 작품/책 우클릭 정리, 표지 사본 보관과 책 질감, 회차 이어 듣기와 자동 넘김, 본문 따라가기 안정화, 낭독자 중심 재생기와 양옆 회차 이동을 포함한다.
합성 카드는 최근 결과를 카드 안에서 듣고 작은 파형을 보며, 목록은 최신순이다. 최종 음성에 사용할 결과 선택은 재생과 분리되어 있다.
공용 음량·증폭·소리 다듬기는 기본 파일 재생과 WaveSurfer 파형에 연결한다. 설정과 스피커 작은 패널은 같은 값을 사용한다. 출력 파일에 음향 효과를 굽지 않는다.

## 검증 근거
세부 기능과 실행 범위는 changelog의 2026-10-03 Codex 항목과 test/e2e/*-mcp.cjs에 남겼다.
최종 소형 패널 실제 앱 20건, 설정 19건, 스피커 실제 출력·복원 16건, 따라가기·증폭 12건 통과. 타입 검사와 빌드 통과.
검사에서 쓴 자료는 격리 앱의 시험 책/합성 음원이다. 사용자 파일의 소리 품질 합격을 뜻하지 않는다. 화면 캡처는 _local에만 보관하며 Git에 올리지 않는다.

## 제외 및 남은 제한
연기 대본 편집기 4파일은 보류 상태로 작업 트리에 보존하고 이번 커밋에서 제외한다. 모델, 로컬 설정, 사용자 자료, 빌드 출력은 추가하지 않는다.
OS 스피커 장치 지연·실제 청취 품질은 이 UI 검증 범위 밖이다. 증폭은 큰 소리의 왜곡 가능성을 없애지 않으며 갑자기 큰 소리 완화는 절대 상한 보장이 아니다.
master 병합은 개발선 문서화·커밋·푸시 뒤 Claude가 수행할 다음 단계이다.
