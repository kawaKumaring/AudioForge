# 카드별 연출 도구 배치와 MiniMax H3 기본 말투 옵션

## 사용자가 보는 변화

화면 머리의 ‘감정’ 단추를 없애고 각 카드의 복사 옆에 아이콘만 배치했다. 복사·연출·고급 옵션·삭제를 한 묶음으로 두어 좁은 창에서도 묶음이 갈라지지 않게 했다. 제목과 설명은 기존 title 툴팁 방식이다.

카드에서 바로 도구를 열어도 그 카드가 삽입 대상이다. 입력칸을 먼저 누르지 않아도 등록된 카드별 편집기로 연결된다. 이미 커서를 둔 카드에서는 그 자리를 쓰고, 처음 쓰는 카드는 대사 앞에 넣는다. 배경 입력을 막지 않는 이동 창은 유지한다.

같은 위치에서 반복해서 누르면 같은 표시를 다시 쌓지 않는다. 다른 감정을 고르면 그 위치의 기존 연출 표시를 바꾼다. 이미지처럼 연출 표시 옆에 일반 감정 이모지가 있으면 한 표시로 묶어 보여 주되, 저장·복사에는 원래 이모지도 그대로 남긴다. 일반 대사 글자는 삭제하지 않는다.

## 기호 연출 보류와 활용 방향

대사 아래의 기호 연출 체크박스·자동 해석 목록을 노출하지 않는다. 현재 작업 파일의 생성 요청에서도 자동 기호 변환을 끈다. 원문, 과거 생성본의 적용 기록, 준비해 둔 코드는 지우지 않는다. 이 기능은 기존 커밋에 포함되지 않았던 미완료 작업이므로 이번 커밋에 통째로 넣지 않는다.

추천 방향은 ‘읽기 편집’이다. 기호를 보고 감정을 추측하는 대신 다음처럼 직접 지정한다.

- 쉼: 원하는 위치에 시간을 지정하고 실제 추가 시간을 보여 준다.
- 발음 예외: 고유명사·숫자 등의 읽는 글을 원문과 따로 확인한다.
- 연출 메모: 호흡·강조·감정의 의도를 대본에 남기되 지원하지 않는 엔진에 적용된 것처럼 말하지 않는다.

이 세 기능을 이번에 새로 구현한 것은 아니다. 기존 자동 기호 해석의 후속 활용 제안이다. H3 감정 실패 판정과 추가 감정 생성 보류는 유지한다.

## H3 생성 방식 연결

참조 목소리 카드의 고급 옵션 → 목소리 생성 방식에 ‘MiniMax H3 · 기본 말투’를 추가했다. 기존 Qwen은 기본값으로 유지한다. 기본 목소리 카드에는 참조를 요구하는 H3 선택을 보여 주지 않는다.

선택은 카드별 저장·복원·요청·생성본 설정 비교에 남는다. 생성 방식을 바꾸면 이전 생성본을 현재 설정과 같은 것으로 표시하지 않는다. H3 요청에는 원문과 실제 준비한 참조, 요청 ID를 전달한다. 일반 카드 처리 통로·GPU 작업 가드·취소 프로세스 종료·결과 표시를 사용한다. H3를 시작하기 위해 Qwen 상주 실행기를 새로 준비하지 않는다.

H3에서는 감정 연출, 말하기 속도 변경, 음높이 변경을 지원 손잡이로 제시하지 않는다. 감정 지시가 들어오면 모델 로딩 전에 거절한다. Speech API 전용 발성·쉼 태그도 H3 대사로 그대로 읽지 않고 거절한다. 기본 말투·명시적 쉼의 기존 대본 문법은 유지한다. Qwen의 말끝 자동 다듬기는 H3 카드 요청에서 끈다.

현재 연결 언어는 한국어다. 대사를 문장·어절 경계에서 최대 170자로 나누고 모든 글자가 남는지 확인한다. 한 어절이 예산을 넘으면 자르지 않고 거절한다. 구간 시간은 글 길이로 추정하며 실제 발화 시간 보장은 아니다. 영상 계산용 캔버스는 256px, 16단계, CFG 1, res_multistep/simple, 영상·소리 shift 12/3이다. 영상 VAE·영상 디코딩·서버는 사용하지 않는다.

모노 참조는 같은 신호를 두 채널로 복제해 오디오 VAE에 전달한다. 원본 파일은 변경하지 않는다. 기본 오디오 VAE 디코더의 표준편차 처리는 유지한다. 그 뒤 출력은 앱의 모노 연결 계약에 맞춰 가장 큰 RMS 채널을 그대로 유지한다. 채널 평균으로 상쇄시키거나 추가 음량 정규화·속도 조절·말끝 자르기를 하지 않는다. 구간별 실제 seed·보낸 글과 지문·프레임·길이·참조 지문·채널 선택을 로컬 기록에 남긴다. 모노화 후의 사람 청취 품질은 이번에 확인하지 않았다.

참조 상한 45초는 앱 어댑터의 자원 보호 규칙이며 모델의 필수 상한이라고 주장하지 않는다. H3 전용 참조 정책을 등록해 GPT-SoVITS 정책으로 잘못 판정하지 않게 했다. 준비된 참조를 다른 목소리로 대체하거나 원본을 임의로 자르지 않는다.

## 앱 내부 준비

설치된 추론 코드의 정적 의존 부분 283개 모듈과 H3 조건·shift·오디오 디코딩 함수를 externals/h3_runtime에 준비했다. ComfyUI 화면·서버·커스텀 노드·미디어 저장 노드는 가져오지 않았다. 원본 GPL-3.0 LICENSE와 파일별 코드 지문을 보존한다. 이 로컬 런타임은 저장소 업로드 대상이 아니다.

REF2VA 본체, Qwen3VL 텍스트 인코더, 오디오 VAE 세 가중치를 externals/h3_models에서 읽는다. 기존 파일을 하드링크로 공유해 대용량 복사와 원본 삭제를 피했다. 추론은 파일을 읽기만 한다. 파일 존재·크기·같은 파일 여부를 확인했으며 전체 가중치 해시 검사는 하지 않았다. 모델이나 코드가 없으면 자동 다운로드·다른 엔진 대체 없이 사유를 낸다.

GPU 여유 6GB를 시작 조건으로 두고 시스템·다른 작업의 현재 사용량과 여유 1.5GB를 예약한다. 이전 시험에서 CUDA 적재량과 실제 GPU 점유가 달라 지연된 일을 반영했다. 완전한 단독 성능 보장이나 모든 메모리 상황의 해결을 뜻하지 않는다.

## 확인한 것과 남은 것

- 도구 조작 21건: 카드 대상, 반복 삽입, 기존 이모지 결합, 원문·복사·잘라내기, 이동·좁은 창 등.
- 관련 요청·규칙 7건: H3 엔진·참조·요청 ID 전달, 자동 기호 변환 없음, 말끝 다듬기 제외, 엔진 변경 시 이전 생성본 판정.
- H3 어댑터 10건: 원문 분할, 단어 보존, 금지 태그·미지원 감정·속도 거절, 모델 누락·변경 거절, H3 참조 정책, 검사 신호의 PCM·참조·seed 보존.
- 렌더러·본체 타입 검사 통과. 앱 내부 런타임 실제 import와 모델 3개 준비 확인. 모델 가중치는 로딩하지 않았다.

실제 앱 화면에서 H3 선택 → 실제 생성 → 결과까지의 경로는 이번에 실행하지 않았다. 새 음성·GPU 생성·사람 청취·전체 게이트·앱 창 실행·화면 캡처도 하지 않았다. 기존 H3 기본 말투 시험과 이번 제품 어댑터의 검증 범위는 별개다. 감정 보류를 해제하지 않는다.

기존 Cosy·기호 자동 해석·말끝 개선의 미커밋 변경과 보류 대본 편집기는 작업 파일에 보존하며 이번 커밋에서 제외한다.
