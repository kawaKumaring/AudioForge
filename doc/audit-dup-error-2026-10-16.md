## 이번에 고친 것

1. **참조 선택 저장 실패를 성공으로 보고하던 것**
   - `src/main/index.ts` `writeSelectedReferenceId` 가 성공 여부(boolean)를 돌려주고, 실패면 앱 로그에 사유 코드를 남긴다.
   - `reference-library.ipc.ts` 선택·해제가 저장 실패면 `SAVE_FAILED` 로 답한다(`referenceLibraryApi.ts` 에 사유 추가).
   - 화면 문구 `SAVE_FAILED`: "참조 선택을 저장하지 못했습니다. 다시 시도해 주세요." 목소리 준비 흐름은 저장 실패를 "다른 구간을 고르라"로 안내하지 않는다(`TTSEditor.tsx`).
2. **파이썬 스크립트 자리 규칙 일곱 곳 → 한 곳**
   - `python-runner.ts` 의 `findPythonScript` 하나로(개발: 묶인 본체 기준 저장소 `python/`, 배포판: `resourcesPath/python`).
   - 카드 미디어 3곳·낭독·자가 점검·Qwen 상주는 '모듈 기준 세 칸 위(묶인 뒤엔 저장소 바깥)' 다음 `process.cwd()` 에 기대고 있었다 → 실행 폴더가 앱 폴더가 아니면 그 기능만 실패. 음높이·분석도 같은 함수로.
3. **검수 도구: 기록 하나 때문에 맥락 전체가 실패하던 것**
   - `tools/mcp/quality_evidence.cjs` `context()` 가 기록별로 읽고, 못 읽은 기록은 `unavailable`(사유 포함)로 남긴 채 나머지는 보인다.
   - ★실제로 깨지는 길: 분석 단계의 파이썬 `json.loads` 는 `NaN` 을 받지만 JS `JSON.parse` 는 거부한다. 잘린 JSON 은 분석 단계에서 이미 거절되므로 점검 때 적은 '잘린 기록' 시나리오는 일어나지 않는다.

고침 (4건)
- 더빙 작업기: 단계 바깥(출력 폴더 만들기·진행 상태 저장) 실패가 잡히지 않아 본체엔 '코드 1 로 끝났습니다' 만 보였다 → `dub_worker.main` 이 사유를 담아 error 를 낸다. 고치기 전 코드로 같은 상황을 돌리면 FileExistsError 로 끝나고 error 알림 0개(확인).
- 음높이 분석: 결과를 못 남긴 파이썬 실패의 원문('Command failed: <파이썬 경로> ...' + 영어 Traceback, 설치 경로 노출)을 화면에 보냈다 → 한국어 사유, 원문은 로그.

- 처리 버튼: IPC 실패가 "Error invoking remote method 'audio:process': Error: ..." 앞머리를 단 채 오류 카드에 보였다 → 앞머리를 뗀다. 트랙 목록에 같은 코드가 있어 `src/renderer/lib/ipcErrorText.ts` 하나로 모았다.

고치지 않음 — 다시 보니 지금은 문제가 아님
- 허용 미디어 확장자 4곳: 목록마다 쓰임이 다르다(일반 열기·영상 판별·더빙 영상 선택·카드 파일 검사). 실제로 막히는 경우(카드에 wmv·flv·ts·mpg)는 이어받은 쪽 작업 중 파일 안이라 손대지 않음.
