# 작업 흐름과 화면 계약

## 현재 기본 화면: 통합 생성 카드

사용자 추가 합의로 음성 합성의 기본 진입은 하나의 생성 카드 화면이다. 문장별/대본·배역 및 한 명/여러 명 구분을 제거했다. 세부 계약은 [통합 카드 GUI](synthesis-card-ui-contract.md)를 따른다. 아래 기존 합성 구성은 **이전 작업 화면**의 기록이며 새 화면의 기준이 아니다. 새 화면은 현재 GUI 검토 단계로 생성/영구 저장/최종 연결은 미연결이다.

2026-09-26 사용자 피드백 반영. 이전의 3단계 카드/본문 설명 방식은 이 문서로 대체합니다.

## 화면 원칙

- 본문에 기능 설명 문단을 배치하지 않습니다. 설명은 툴팁, 화면에는 입력명·조작·짧은 상태를 둡니다.
- 합성은 하나의 작업면: 탭 → 목소리 도구막대 → 대사 편집 → 실행 영역입니다. 숫자 카드와 중복 설명을 없앱니다.
- 대본·배역 편집의 기본 화면에는 대사가 중심입니다. 감정·쉼은 접어 두고, 말투·참조·엔진·분석은 설정 패널에서 엽니다.
- 여러 배역은 대사 행으로 표시하며 인물 선택, 이름 변경, 목소리 상세, 순서 변경을 기존 원문 patcher에 연결합니다. renderer가 새 parser를 만들지 않습니다.
- 문장별 제작의 문장·테이크·채택·이어 듣기 동작은 보존합니다. 가져오기는 기존 대본 뒤에 추가하며 여러 배역을 단일 목소리로 조용히 변환하지 않습니다.
- 파일 작업은 공통 원본을 사용합니다. 메뉴와 합성 탭은 실행/취소 정리 중 잠깁니다. 이전 다른 작업 결과를 합성 완료처럼 표시하지 않습니다.
- 기존 180ms 전환과 작업 상태 모션을 유지하며 prefers-reduced-motion을 존중합니다. 탭 키보드 동작과 focus 표시는 유지합니다.

## 노래 변환

- 외부 메뉴는 '노래 변환'입니다. 음원·영상의 가창 목소리 변환, 장래의 번역 가창이 범위입니다.
- 현재 GUI에 연결된 dub는 영상 대사 번역/TTS 경로입니다. 기존 더빙 실험으로 접어서 보존하고, 노래 변환 연결 검토와 언어 변환 예정 상태를 표시합니다.
- song_chain.py/song_voice.py/song_reference.py 노래 코드가 별도로 존재하지만 src에서 연결되지 않았습니다. 이름 변경을 가창 기능 구현으로 간주하지 않습니다.
- 1차 구현은 기존 노래 음색 변환을 오디오/비디오 입력부터 결과 비교까지 연결하는 것입니다. 번역 가창은 별도 후속 과제이며 번역+일반 TTS+시간 늘이기만으로 완료라 하지 않습니다.

## Claude가 구현할 상태 계약 (이번 GUI 변경에는 미포함)

- 시작 시 활성 원본/목소리는 비웁니다. 저장된 작업은 삭제하지 않습니다.
- 새로 불러온 파일을 모든 작업의 초기 참조로 채택합니다. 작업별로 목소리를 변경하면 그 작업에서만 유지합니다.
- 새 원본 설정 후 합성에 처음 들어갈 때 이전 작업이 있다면 복원 여부를 한 번 묻습니다. 자동 덮어쓰기/묵시적 복원을 금지합니다.
- 현재 대본·배역 참조는 공통 fileInfo를 공유하고 문장별 제작은 별도 목소리입니다. 이 소유권 차이는 아직 남아 있습니다. 버튼 명칭 변경을 상태 이관 완료로 보지 않습니다.
- 원본/참조/임시 구간/대본/테이크의 소유권과 정리 범위를 분리하여 다른 작업을 지우지 않아야 합니다.

## 파일 읽기와 검증 한계

- 파형은 로딩/준비/실패를 구분하고 실패 시 경로와 다시 읽기를 제공합니다. 디코드 실패를 무음으로 표시하지 않습니다.
- 같은 원본의 메뉴 변경은 파형 색만 바꿉니다. 사라진 화면에 늦은 비동기 응답을 반영하지 않습니다.
- 로그에 파일 없음과 옛 경로가 확인되었지만 단순 합성 왕복으로 파일이 삭제된다는 가설은 격리 검사에서 재현되지 않았습니다. 동명 파일을 임의 연결하지 않습니다.
- Electron UX 검사는 격리 WAV와 모델 IPC/공식 parser fixture를 사용합니다. 음성 품질·가창 성능 검증이 아닙니다.

## 인물 파형 (추가 요청)

- 참조를 가진 배역의 대사 행에는 높이 40px의 파형·재생·선택 구간만 표시합니다. 전체 파일 카드와 메타데이터를 반복하지 않습니다.
- 기존 WaveSurfer와 local-file 경로를 재사용하며, 구간 수정은 기존 목소리 설정에 둡니다. 축소 파형은 목소리/구간을 변경하지 않습니다.
- 축소 파형끼리 동시 재생하지 않으며, 작업 중에는 잠그고 화면 해제 시 재생/디코드를 정리합니다. 파일 읽기 실패에는 다시 읽기를 제공합니다.
