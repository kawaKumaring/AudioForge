# 작업 목록 선택 제거

각 작업의 선택칸, 전체 선택, 선택 제거를 추가했다. 저장 카드 작업과 옛 작업을 같이 고를 수 있다. 저장 카드 작업에도 개별 제거 아이콘을 제공한다. 제거 전 대상 수와 파일 유지 범위를 확인한다.

이 조작은 작업 목록의 기록을 제거한다. 음원과 별도 대사·연기 지시 파일은 유지한다. 카드 안의 카드 제거는 별도 기능이다. 여러 작업은 순서대로 제거하고 실패 항목은 성공으로 표시하지 않는다. 보관함은 역순으로 제거해 번호 이동에 따른 다른 작업 삭제를 막는다. 작업 중 목록 조작과 닫기는 막는다.

합성 자료만 사용한 실제 앱 MCP 검사 11건 통과, 화면 오류 0건. 선택 두 건 제거와 전체 제거, 원본 음원 유지 확인. 렌더러 타입 검사·빌드 통과. 새 음성 생성·전체 검사는 하지 않았다.
