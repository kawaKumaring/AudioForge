# 새 화면 기준 — 무엇을 어디서 검사했나, 무엇이 아직 옛 화면에만 있나

2026-09-27. **새 검사를 돌려 만든 문서가 아니다** — 이미 통과한 검사의 근거를
화면별로 갈라 적은 것이다(관리자 지시: 통과한 검사는 변경 영향이 없으면 다시 돌리지 않는다).

## 0. 검사를 세 종류로 나눈다

★**옛 버전 검사나 엔진 단독 성공을 새 GUI 기능 완료의 근거로 쓰지 않는다.**

- **(가) 개발 중 GUI의 실제 작업 경로** — 새 화면에서 사람이 누르는 길을 그대로 탄 것
- **(나) 옛 버전 유지·회귀** — 옛 화면이 아직 망가지지 않았는지 보는 것
- **(다) 엔진 단독** — 화면 없이 파이썬·모델만 돌린 것

그리고 (가) 안에서도 **실제 엔진**과 **모의 응답**을 따로 적는다.

## 1. 음성 합성 — [개발 중] 탭(생성 카드)

### (가) 새 GUI 실제 경로 — 실제 엔진

| 구간 | 검사 | 결과 |
|---|---|---|

| 껐다 켜기 → 사용자가 '불러오기' → 되살린 카드로 바로 생성 가능 | `synthesis-cards-restart.e2e.mjs` | **14건 통과** · 실제 piper |
| 최종 음성 이어 듣기·파일 저장·원본 보호 | `synthesis-cards-join.e2e.mjs` | **20건 통과** · 실제 `card_join.py` |

### (가) 새 GUI 실제 경로 — 모의 응답(모델만 대체)

| 구간 | 검사 | 결과 |
|---|---|---|
| 카드 화면 전반·채택 표시·최종 구성 이동·모션·팝업 | `synthesis-cards.e2e.mjs` | 64건 통과 · **합성 IPC 0회** |
| 준비·생성·저장·복원·요청 대조·취소·실패 | `synthesis-cards-connection.e2e.mjs` | 29건 통과 |

### (나) 옛 버전 유지·회귀

`tts-convenience-dev` · `restore-race-dev` · `playback-volume` · `reference-ready-consistency` ·
`synthesis-voice-isolation` · `work-draft-restore-notice` · `dialogue-edit` · `transcript-edit` ·
`ux-workflow`(93건) — 게이트에서 전부 통과.
★이 통과는 **옛 화면이 살아 있다**는 뜻이지 새 화면이 그 기능을 갖췄다는 뜻이 아니다.

### (다) 엔진 단독

`card_join.py` 21건 · 파이썬 전량 3,162건(152/152 파일).

### 이 경로에서 **확인하지 않은 것**

- **파일 참조 목소리로 실제 GPU 합성**을 새 카드 화면에서 끝까지 — 카드 검사는 실제 엔진을
  기본 목소리(piper)로만 탔다. 참조 목소리 실제 생성은 **옛 화면 검사**(GPU 3단계)에서만 돈다.
- 생성본 **듣기**(재생)와 **채택 전환**은 모의 응답 검사에서 단추·상태로만 봤다. 소리는 안 들었다.

## 2. 노래 변환 — 새 화면

### (가) 새 GUI 실제 경로 — 모의 응답

| 구간 | 검사 | 결과 |
|---|---|---|
| 화면 진입 · 고르기 전 차단 · 진행 표시 · 멈추기 · 멈춘 뒤 재시도 · **멈춰도 선택 유지** · 실패 사유 · 실패 뒤 재시도 · **지난 요청 무시** · 원본 바이트 보존 · 취소 실패 표시 · **저장 식별자 전달** | `song-convert.e2e.mjs` | **20건 통과** |

### (가) 새 GUI 실제 경로 — 결과 카드(컴포넌트)

`song-result.component.mjs` 8건 통과 — 실제 React 컴포넌트 + WaveSurfer 대역.
★**실제 파일 디코딩·재생 청취는 하지 않았다**(Codex 문서 명시).

### (다) 엔진 단독 — 실제 엔진

| 입력 | 확인 | 결과 |
|---|---|---|
| 음원(합성 12초) | `song_worker.py` 직접 | 사슬 완주 · 변환 음원 12.00초 · 원본 불변 |
| **영상(10초 mp4)** | `scripts/song-video-check.mjs` | **13건 통과** · 32초 · 꺼낸 소리와 변환 음원 **둘 다 9.985초** |
| 계약·진입점 단위 | `songJob.test.ts` 21 · `test_song_worker.py` 10 · 노래 파이썬 66 | 통과 |

### 이 경로에서 **확인하지 않은 것**

- **새 화면에서 실제 엔진까지** 한 번에 — 화면 검사는 모의 응답이고, 실제 엔진은 화면 없이 돌렸다.
  둘을 잇는 구간(화면 클릭 → 진짜 `song:run` → 몇 분 뒤 결과)은 **아직 한 번도 통과로 확인하지 않았다.**
- **저장(`song:export`)의 진짜 본체 대조** — 화면이 올바른 식별자를 넘기는 것까지 확인했고,
  본체가 거절하는 규칙은 코드와 모의 문지기로만 봤다.
- **원곡/변환본 비교 재생** — 컴포넌트 대역으로만. 실제 파일로 소리를 낸 적 없다.

## 3. 새 화면에서 옛 화면으로 들어가야만 쓸 수 있는 기능

판정 규칙: **이름이나 버튼이 있다는 이유로 완료로 적지 않는다.** 코드에서 확인한 것만 '연결 완료'.

### 음성 합성 — [옛 버전] 탭에서만 되는 것

| 기능 | 상태 | 근거 |
|---|---|---|
| 대본을 통째로 쓰기·붙여넣기 | **미연결** | 카드는 카드마다 대사를 쓴다. 통째 입력 경로 없음 |
| 여러 배역 대본 해석(배역 표기 파서) | **미연결** | 카드에 파서 없음 |
| 배역 추가·이름 바꾸기·배역별 목소리 묶음 | **미연결** | 카드 하나 = 목소리 하나. 묶음 개념 없음 |
| 감정 지정·감정별 참조 등록 | **후속** | 엔진에 스칼라 감정 입력이 없다. 감정 시험은 현재 보류 |
| 참조 목표 길이 조절 | **미연결** | 카드는 제품 기본값 고정(`productDefaults`) |
| 엔진·모델 판 고르기 | **미연결** | 카드는 `auto`(기본 목소리는 그 모델) |
| 말끝 다듬기 세부(tailMode·padding·fade) | **미연결** | 카드에서 고를 수 없다. 제품 기본값으로 전송 |
| 말끝 잘림 표시(`tailResidual`) | **미연결** | 카드 생성본 구조에 자리 없음 |
| 참조 자산 라이브러리 | **미연결** | |
| 미완 줄·유령 발화 표시 | **미연결** | |
| 문장 사이 쉼(`silenceGap`) | **부분** | 카드에는 없고 최종 연결의 **카드 사이 간격**만 있다. 뜻이 다르다 |
| 전체 생성 대기열 | **후속** | 카드는 한 번에 하나 |
| 연결부만 따로 듣기 | **미연결** | 자리만 있고 비활성(툴팁으로 사유 표시) |
| 옛 작업을 카드로 가져오기 | **미연결** | 조사 완료(`doc/legacy-to-cards-survey.md`), 구현 없음 |
| 문장별 제작(생성·채택·듣기·폴더) | **연결 완료** | 카드에서 됨(위 1장 검사) |
| 참조 구간 직접 지정 | **연결 완료** | 카드 고급 옵션(참조 목소리일 때) |
| 속도·음높이 | **연결 완료** | 카드별 적용, 범위 보정 표시 |
| 최종 이어 듣기·저장 | **연결 완료** | |

### 노래 변환 화면에서 옛 화면(기존 더빙 탭)으로 가야 하는 것

| 기능 | 상태 | 근거 |
|---|---|---|
| 영상 대사 번역·더빙(알아듣기→번역→말하기) | **별도 탭 유지** | `DubWorkspace` 를 그대로 띄운다. 노래 변환으로 대신 잇지 않았다 |
| 더빙 작업 폴더·이전 결과 불러오기 | **별도 탭 유지** | |
| 번역 가창(번역 가사를 멜로디에 얹기) | **후속** | 화면에 '예정' 으로 표시. 코드 없음 |
| 영상 재결합(변환 음원을 영상에 다시 넣기) | **미연결** | 우선 목표가 음원 출력이었다 |
| 주보컬/화음 2차 가르기 선택 | **미연결** | 엔진에는 있으나 화면에서 고를 수 없다(기본 꺼짐 고정) |
| 원곡·목소리 고르기 → 변환 → 비교 → 저장 | **연결 완료** | 위 2장 검사 |

## 4. 이번에 확인한 범위 요약

- **어느 화면**: 생성 카드(개발 중), 노래 변환(새 화면), 옛 버전 탭(회귀 유지 확인)
- **실제 엔진 사용**: 기본 목소리 piper(카드), `card_join.py`(최종 음성),
  분리 모델 + seed-vc(노래 변환, 음원·영상 둘 다)
- **어디까지 확인**: 파일 생성 ○ / 저장 ○(카드 최종 음성은 앱 경로, 노래는 엔진 경로) /
  **재생은 단추·상태까지만** — 실제 소리로 확인한 적 없음
- **청취 품질 확인자**: **아무도 없다.** 나는 어떤 소리도 듣지 않았다
- **간헐 실패 1건**: 게이트에서 `생성 카드 화면` 이 7.0초에 한 번 실패했고 단독 실행과
  게이트 재실행에서는 통과했다(64건·28단계). 원인 미확인 — **통과로 덮지 않고 적어 둔다**
- **건너뜀**: GPU 합성 3단계(`--app` 으로만 돈다. 이번 변경과 무관해 반복하지 않았다)
