# 통합 생성 카드 GUI 계약

2026-09-26 사용자와의 토론으로 확정한 구조. 문장별/대본·배역 및 한 명/여러 명은 새 화면에서 나누지 않는다.

## 현재 범위

실제 앱 안의 GUI 우선 구현이다. 독립 HTML은 만들지 않는다. 새 카드의 엔진·영구 저장·연결 출력은 다음 구현 범위이며, 임의의 성공 결과나 가짜 파일을 만들지 않는다. '연결 전' 상태와 비활성 실행 버튼으로 표시하고 상세 사유는 툴팁으로 제공한다.

기존 기능은 '이전 작업'으로 보존한다. 파일/원본/기존 lab/대본 저장을 수정하거나 자동 이관하지 않는다. TTS 결과 폴더 복원은 기존 제작 화면으로 이동한다. 새 GUI의 상태는 현재 renderer 실행 안에서만 유지된다.

## 카드 구성

- 한 카드가 참조 원본·목소리·선택 구간·대사·설정·생성본·채택을 소유한다.
- 최초 공통 원본을 초기 카드로 채택한다. 이후 카드의 원본 변경은 그 카드에만 반영한다.
- 추가 버튼은 클릭과 파일 드롭을 지원한다. 카드 파일명/파형 자리의 드롭은 해당 카드만 교체한다. 카드 하나에 여러 파일을 떨어뜨리는 모호한 교체는 거부한다.
- 손잡이 드래그 및 Alt+↑/↓로 묶음 전체의 순서를 바꾼다. 파형 드래그와 카드 이동을 구분한다.
- 복제는 참조·설정만 복사한다. 새 ID, 빈 대사, 빈 생성본으로 시작한다.
- 삭제는 카드 UI만 제거하며 되돌릴 수 있다. 디스크 파일은 지우지 않는다.
- 대사와 참조 파일은 늘 가까이 표시한다. 설명 문단을 추가하지 않는다.

## 팝업

- 고급 옵션: 해당 카드의 초안을 편집한다. 적용 전에는 변경하지 않는다. 취소/Escape는 되돌린다. 구간 끝은 시작보다 크고 파일 길이 이하여야 한다.
- 생성본: 생성 순서대로 표시한다. 행에는 채택·재생·파일 위치·당시 대사 조회가 있다. 대사 조회는 같은 팝업 안에서 펼친다.
- 스냅샷은 생성 당시의 대사·원본·설정이다. 현재 대사를 덮어 표시하지 않는다. 선택 결과가 현재 설정과 다르면 '수정 전'으로 표시한다.
- native dialog를 사용하여 배경 입력을 막고 Escape·초점 이동/복원을 제공한다. 모달 위 모달은 만들지 않는다. 모달 전환 시 카드 파형 재생을 종료한다.

## 최종 음성

- 카드 밖 하단: 채택 수, 전체 이어 듣기, 연결 조정, 파일 저장.
- 연결 조정: 기본 간격, 인접 카드 ID 쌍별 간격, 음량 맞추기, 경계 다듬기. 설정과 실제 음성 처리는 구분한다.
- 전체 재생·연결부 재생·저장은 실제 백엔드 연결까지 비활성이다.

## 연결 경계

주요 파일은 SynthesisCardWorkspace.tsx, synthesisCards.store.ts, SynthesisTabs.tsx이다. 기존 LabWorkspace/TTSEditor의 엔진 경로는 보존한다. 새 카드의 영구 저장, 구간 추출, 준비 상태, 큐/취소, 생성 결과 스냅샷, legacy 이관, 영상 오디오 추출, 출력 계획은 Claude가 연결한다. UI 입력명/범위와 엔진 capability 매핑도 확인해야 한다.
