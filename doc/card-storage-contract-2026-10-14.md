# 합성 카드 저장 구조 재정의 — 2026-10-14

최신 사용자 지시는 이전의 코드만 두기 계획과 자동 이전 대사 보관 계획을 대체한다. 앱 내부에는 카드 정보와 입력 파일 경로를 두며 사용자 대사·프롬프트·연기 지시는 결과 위치의 별도 파일로 관리한다.

## 저장 규칙

설정의 합성 카드 자동 저장 체크는 기본 꺼짐이다. 켰을 때 카드 순서·목소리·생성본 선택·입력 파일 경로를 저장한다. 서로 다른 카드 작업을 시작하면 앞 작업은 보관 목록에 남긴다. 타이핑할 때마다 이전 대사 사본을 쌓지 않는다. 체크를 끄면 예약 쓰기와 창 종료 쓰기도 멈춘다.

카드의 대사·연기 지시 저장 버튼은 자동 저장과 독립이다. 생성본이 있으면 그 음원 옆 card-지문.input.json에, 생성 전이면 기존 결과 저장 설정의 AudioForge_output/음성합성/작업대본에 저장한다. 본체가 경로를 정한다. 이후 결과 폴더가 바뀌면 이전 입력 경로도 카드 정보에 남겨 명시적 카드 제거에 포함한다. 따로 저장한 입력 파일은 자동 저장을 끈 상태에서도 대사·지시 불러오기 버튼으로 열 수 있다. 목소리·생성본을 대본 불러오기로 바꾸지 않는다.

생성본의 대사는 현재 카드와 별개인 take-지문.input.json에 저장한다. 생성 후 카드를 고쳐도 당시 대사·지시가 바뀌지 않는다. 내부 카드 메타에는 원문과 연기 지시를 넣지 않는다. 사용자 입력 파일의 소유 표·형식을 읽을 때 확인하며 파일 누락·손상을 빈 작업으로 성공 처리하지 않는다.

## 불러오기와 옛 기록

작업 불러오기 한 입구에서 카드 작업과 옛 작업을 함께 보여 준다. 둘 다 내용 보기에서 대사를 확인할 수 있다. 옛 자료는 복사해 새 카드 식별자를 부여하며 따로 한 벌 가져온 카드끼리 삭제가 연결되지 않는다. 옛 원문은 내부 설정 대신 외부 입력 파일 경로로 바꾸며 읽기와 변환 경로를 유지한다. 구형 입력의 갱신은 두 교대 파일을 사용해 설정 저장 실패 때 활성 대본을 덮지 않는다. 자동 파일 삭제는 하지 않는다.

기존 카드 원문은 외부 저장이 성공한 뒤 내부 메타에서 제거한다. 이 코드는 앱 사용 시 이관되며 이번 작업에서 실제 사용자 설정 파일을 열거나 옮기지는 않았다.

## 카드 제거

카드 제거를 누르면 취소 / 음원 유지 / 음원도 삭제를 묻는다. 해당 카드의 메타·입력 파일 경로들을 제거한다. 음원 삭제는 원본과 다른 카드가 쓰는 경로를 보호하고, 해당 음원을 등록한 음성합성 세션이 있는 경우에만 허용한다. 파일 삭제 후에는 메모리 되돌리기 단추로 되살리지 않는다. 파일·메타 제거 실패는 완료로 표시하지 않는다. 파일 여러 개의 삭제는 운영체제 전체 거래가 아니므로 도중 오류 때 일부 파일이 이미 제거됐을 수 있으며 앱에서 실패 사유를 보고 재확인해야 한다.

자동 승인 검토가 저장 때의 이전 입력 자동 삭제와, 카드 제거 때 인접 session.json/H3 기록까지 제거하는 변경을 거절했다. 따라서 자동 삭제는 구현하지 않았고, 카드에 속하는 입력 파일과 선택된 음원만 제거한다. 기존 생성 세션·H3 기록에 남은 원문까지 없애는 정리는 별도 승인이 필요하다. 기존 시험·진단 자료를 임의 삭제하지 않았다.

## 검사와 범위

관련 단위 88건과 렌더러·본체 타입 검사 통과. 새 파일 저장·읽기·삭제 검사는 검사용 임시 파일로 수행했다. 읽기 실패 검사는 빈 작업 반환 대신 저장 차단을 확인하도록 강화했다. 시험 고정물 문법과 구형 기록 함수 인자 누락을 보완했다. 사용자 추가 지시 후 MCP로 실제 앱의 격리 프로필을 실행했다. 검사용 카드·옛 기록 18개, 내용 보기, 1100px·760px 화면 검사 6건 통과·오류 0건, 캡처 3장을 직접 확인했다. 사용자 데이터·실제 목소리는 사용하지 않았고 새 음성 생성·전체 검사는 하지 않았다.

합성 재현 기록도 새 생성부터 음원 폴더의 .generation-record/실행 식별자 아래에 저장하며 결과 메타에는 위치를 남긴다. 개발 검사의 명시적인 기록은 기존 격리 규칙을 유지한다. 관련 파이썬 검사 39건 통과.

이번 구현은 합성 카드와 옛 합성 기록 저장을 대상으로 한다. 낭독 본문·받아쓰기 교정·다른 모드와 과거 진단 기록 전체의 이전은 포함하지 않는다. 보류 중인 연기 대본 편집기 및 다른 미커밋 엔진 변경은 포함하지 않는다.
