# 옛 작업 자동 저장 보존·결과 위치 — 2026-10-14

사용자가 옛 작업 가져오기 목록이 자동 저장 후 사라진다고 보고했다. 코드에서 문장별 제작 기록이 한 칸이고 합성 전 자동 저장은 원본 경로 한 칸씩 대체되는 것을 확인했다. 합성 결과 파일 삭제와는 별개다. 사용자 설정 파일을 열어 재현하지는 않았다.

설정 저장 본체가 바꾸기 전 기록을 이전 저장 보관함에 같은 원자 저장으로 남긴다. 시각만 바뀐 저장은 제외하고 내용 지문이 같은 기록은 중복 보관하지 않는다. 갯수로 지우지 않는다. 가져오기 목록에 이전 저장을 표시하며 각각 읽기·가져오기·위치 열기·명시 삭제가 된다. 삭제한 보관본은 현재 문장별 작업을 초기화하지 않는다. 사용자가 작업 기록 전체 비우기를 고르면 보관함도 함께 비운다.

위치 버튼은 해당 가져오기 문서의 가장 최근 생성본 경로를 우선 탐색기에서 표시한다. 생성본 기록이 없으면 참조 원본으로 간다. 소리 파일을 열거나 이동하지 않는다.

관련 검사 34건과 렌더러·본체 타입 검사 통과. 두 보완 과정에서 직접 실행용 모듈 경로와 보관본 삭제 분기 누락을 찾아 고쳤다. 앱 실행·캡처·음성 생성은 하지 않았다. 이미 덮인 과거 기록은 이 변경으로 복원되지 않는다. 새 보관 기능은 설치 후부터 적용된다. 내용 변경마다 보관하므로 기록이 늘어날 수 있다. 사용자가 명시적으로 정리하기 전 자동 삭제하지 않는다.
