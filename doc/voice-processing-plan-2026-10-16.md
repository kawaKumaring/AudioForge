# 음성 처리 체인 + 음성 편집 패널 계획 (2026-10-16)

사용자 지시(2026-10-16): CraftSource(SoundCraft·EffectCraft) 분석에서 나온 흡수 권장을 구현하고, 아래를 더한다.
- 크로스페이드·겹치기 — 여러 명이 대화할 때 **상대 말 중간에 끼어들기**, 필요하면 **동시에 말하기** 연출.
- 일반 음성 편집 체인 — 노이즈 제거 → 저음 자르기(HPF)·EQ → 컴프레서 → (선택) 리버브 아주 약하게(mix 2~5%).
- 치찰음 줄이기(DeEsser) — 사용자가 말하는 "전파 소리"일 수 있다.
- 쓰는 곳 두 군데: ① 음성 생성 고급 설정 ② 새 좌측 패널 "음성 편집". 끼어들기에는 크로스페이드 + **실시간으로 들으며 조절**이 필요하다.
- 화면 조작(음원 바 겹치기 드래그 등)도 함께 설계한다. 진행은 **개발툴 MCP 를 적극 활용**해 실제 앱으로 확인한다.

근거 조사: SoundCraft·EffectCraft 코드(경로는 아래 각 항목), AudioForge 현재 구조.

## 1. 핵심 설계 결정 — 처리 엔진은 하나

- **실시간 듣기와 저장 결과가 같은 소리여야 한다.** 두 곳(화면·파이썬)에 같은 처리를 따로 만들면 반드시 어긋난다.
- 그래서 음성 편집 체인은 **화면 쪽 Web Audio 한 벌**로 만든다.
  - 실시간 듣기: AudioContext 그래프(파라미터 변경은 `setTargetAtTime` 약 20ms 스무딩 — SoundCraft `dsp/src/params.rs` 의 1-pole 20ms 와 같은 생각).
  - 저장: **같은 그래프를 OfflineAudioContext** 로 렌더 → 들은 소리 = 저장된 소리.
  - 기본 노드로 되는 것: 저음 자르기·EQ(BiquadFilter), 리버브(Convolver + 생성한 잔향).
  - 직접 만드는 것(AudioWorklet): 리미터(SoundCraft Maximizer 이식), 치찰음 줄이기(SoundCraft DeEsser 이식), 컴프레서(브라우저 DynamicsCompressor 는 동작이 정의되지 않은 부분이 있어 SoundCraft `compress_gr` 이식으로 결과를 고정), 노이즈 제거.
  - 이미 있는 바탕: `src/renderer/lib/playbackEffects.ts`(실시간 lowshelf·peaking·압축) — 재생 보정용이라 그대로 두고 새 체인은 따로.
- 음성 생성 고급 설정도 같은 체인을 쓴다: 생성된 파일을 화면에서 OfflineAudioContext 로 처리해 저장(카드가 화면 쪽에 있다).
- 예외: **노래 변환**은 파이썬 사슬이라 리미터만 파이썬으로 따로 둔다(작은 순수 함수, 시험으로 같은 동작 고정).

## 2. 노이즈 제거 재료

- SoundCraft·EffectCraft 모두 노이즈 제거가 **없다**.
- 후보: RNNoise(작은 신경망, 48kHz 실시간, BSD) 를 AudioWorklet(wasm) 로 → 실시간·저장 모두 가능. **다운로드 필요 — 사용자 승인 대기.**
- 대안(다운로드 없음): 스펙트럼 게이팅 직접 구현 — 품질이 낮고 "물속 소리" 부작용이 잦다.

## 3. "전파 소리"

- 치찰음일 수도 있지만, 대역이 좁은 무전기 같은 소리·압축 잡음일 수도 있다. 치찰음 줄이기로 해결된다고 장담하지 않는다.
- 확인: 사용자가 그렇게 들은 결과 하나를 승인받아 대역별 에너지를 재고(6~9kHz 치찰음 대역 vs 대역 폭), 치찰음 줄이기 전후를 청취 비교.

## 4. 겹치기(끼어들기) 모델 — SoundCraft 편집 모델 기준

- **화자당 트랙 하나.** 같은 트랙 안에서는 겹치지 않는다(나중 클립이 덮음). 예외는 크로스페이드 구간만. 동시 발화·끼어들기는 **트랙끼리 겹침**으로 표현한다(SoundCraft `engine/src/edit.rs` 1-6행).
- 크로스페이드 곡선 기본 EqualPower(+ Linear), 곡률 하나(SoundCraft `dsp/src/offline.rs` FadeShape, `model/src/clip.rs`).
- 기본 크로스페이드 길이는 원본 코드에 없다 → 우리가 정한다(시작값 20ms, 청취로 조정).
- 기존 카드 이어 붙이기(`cardJoinPlan.ts` 간격 0~5초, `card_join.py` "겹치지 않는다")는 **고치지 않는다** — 이어받은 쪽 작업 중 파일이고, 그 규칙은 카드 기능의 계약이다. 겹치기는 음성 편집 패널의 새 혼합으로 만든다.
- 겹치면 합산 최대치가 커진다 → 출력 끝에 리미터 필수.

## 5. 화면 조작 (v1 최소 집합)

SoundCraft `ui-egui/src/edit_window.rs`, EffectCraft `ui-egui/src/panels/timeline.rs` 의 실제 수치를 기준으로 한다.
- 클립 이동: 본체 드래그. 다른 트랙 위로 겹치기 자유, 같은 트랙은 덮어쓰기.
- 트림: 바깥 4px + 안쪽 5px(짧은 클립은 폭의 1/3), 원본 끝에서 멈춤.
- 페이드: 클립 위쪽 모서리 14px 를 끌어 만들고, 있는 손잡이는 ±8px 로 잡는다. 곡률은 중간점 세로 드래그(페이드 폭 32px 미만이면 숨김).
- 크로스페이드: 같은 트랙에서 두 클립 경계를 겹치게 끌면 생성.
- 클립 음량: 세로 드래그 한 값(dB). 드래그 한 번 = 되돌리기 한 단계(SoundCraft `execute_merged`).
- 스냅: Ctrl 로 켜고 끄기 반전, 넛지 ±.
- 듣기: 재생 위치부터 재생, 선택 구간 반복, 트랙 솔로·음소거, 조절 중 바로 반영.
- 미터: 트랙별 최대치(초당 20dB 하강, 2초 유지) + 출력 단기 음량(LUFS) + 압축량.
- 파형: 초당 200칸 최대·최소 요약을 한 번 만들어 모든 확대에서 재사용(EffectCraft `waveform.rs`).
- 뺀 것(v1 과함): 밀어내기(ripple)·잠금·격자/템포·음량 곡선·서라운드·외부 플러그인.

## 6. 처리 기본값 (SoundCraft `dsp/src/plugins/` 기본값에서 음성용으로 조정)

- 저음 자르기 80Hz 12dB/oct(EQ7 HPF 기본 80Hz).
- 컴프레서 −20dB · 4:1 · 공격 10ms · 해제 100ms · 무릎 6dB(Compressor 기본).
- 치찰음 6kHz · 문턱 −30dB · 최대 10dB(DeEsser 기본).
- 리버브 기본 꺼짐, 켜면 mix 3%(사용자 지시 2~5%). SoundCraft Room 기본 25% 는 음성에 과하다.
- 리미터 최대치 −1dBTP, 앞보기 1.5ms, 해제 50ms(Maximizer 기본, 최대치만 음성 배포용으로 −1).
