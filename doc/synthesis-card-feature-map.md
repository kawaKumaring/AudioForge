# 옛 두 화면 → 생성 카드 기능 대응표

2026-09-27. 관리자 지시 4항.
**이름이 같다는 이유로 연결 완료로 보지 않는다.** 코드에서 확인한 것만 '가능' 으로 적는다.
이 표는 보고 문서다 — 앱 화면에는 넣지 않는다.

구분
- **가능** — 카드에서 실제로 되고 검사로 확인했다.
- **부분** — 비슷한 일을 하지만 같지 않다. 무엇이 다른지 적는다.
- **미연결** — 카드에 없다. 옛 버전 탭에서만 된다.
- **후속** — 이번 범위 밖으로 정해 둔 것.

## 문장별 제작 (옛 버전 · 합성 > 문장별 제작)

| 옛 기능 | 카드 | 비고 |
|---|---|---|
| 목소리 파일 고르기 | 가능 | 목소리 고르기 > 음성·영상 파일 |
| 참조 없는 기본 목소리 | 가능(카드에만 있다) | 옛 화면에는 없던 것 |
| 공통 원본의 목소리 쓰기 | 부분 | 첫 카드에 초기값으로만 들어온다. 옛 화면의 '원본 목소리 쓰기' 단추에 해당하는 조작은 없다 |
| 문장 추가·삭제·되돌리기 | 가능 | 카드 추가·삭제·되돌리기 |
| 문장 순서 바꾸기 | 가능 | 손잡이 드래그·Alt+↑↓ |
| 문장별 생성 | 가능 | 카드 생성 |
| 생성본 여러 개 보관 | 가능 | 다시 만들어도 이전 것이 남는다 |
| 생성본 채택 | 가능 | 사람만 바꾼다(재생성이 건드리지 않는다) |
| 생성본 듣기 | 가능 | 생성본 팝업 |
| 생성본 폴더에서 보기 | 가능 | 생성본 팝업 · 파일 위치 |
| 말끝 잘림 표시 | **미연결** | 카드에 그 표시가 없다(코드에 `tailCut` 없음). 만들 때 말끝 다듬기는 보내고 있으나 **잘렸는지 알리지 않는다** |
| 전체 이어 듣기 | 가능 | 최종 음성 · 전체 이어 듣기 |
| 이어 붙여 내보내기 | 가능 | 최종 음성 · 파일로 저장 |
| 작업 멈추기 | 가능 | 생성 중 멈추기 |
| 상태·사유 표시 | 가능 | 카드 상태 줄 + 툴팁 |
| 문장 사이 쉼 조절 | 부분 | 카드에는 문장별 쉼 손잡이가 없다. 최종 연결의 **카드 사이 간격**으로만 조절한다 |

## 대본·배역 편집 (옛 버전 · 합성 > 대본·배역 편집)

| 옛 기능 | 카드 | 비고 |
|---|---|---|
| 대본을 한 번에 쓰기 | **미연결** | 카드는 카드마다 대사를 쓴다. 대본 통째 입력·붙여넣기 경로가 없다 |
| 여러 배역 대본 해석 | **미연결** | 배역 표기를 읽는 파서가 카드에 없다 |
| 배역 추가·이름 바꾸기 | **미연결** | 카드에는 배역 개념이 없다. 카드 하나가 목소리 하나다 |
| 배역별 목소리 지정 | 부분 | 카드마다 목소리를 따로 두는 것으로 같은 결과를 낼 수 있으나, **한 대본 안의 배역**이라는 묶음은 없다 |
| 배역 목소리 준비 재시도 | **미연결** | 카드는 조건이 바뀌면 다시 준비하지만 '다시 시도' 단추가 없다 |
| 감정 지정 | **후속** | 엔진에 스칼라 감정 입력이 없다. 감정별 참조 클립 등록이 필요하다 |
| 감정별 목소리 등록 | **후속** | 위와 같은 이유 |
| 쉼 넣기(문장 사이) | 부분 | 최종 연결의 간격으로만 |
| 참조 구간 직접 지정 | 가능 | 카드 고급 옵션(참조 목소리일 때만) |
| 참조 목표 길이 조절 | **미연결** | 카드는 제품 기본값을 쓴다 |
| 엔진 모델 판 고르기 | **미연결** | 카드는 엔진 `auto`(기본 목소리는 그 모델) |
| 참조 자산 라이브러리 | **미연결** | |
| 미완 줄·유령 발화 표시 | **미연결** | |
| 이전 작업 되살리기 | 가능(카드 자리 따로) | 카드 작업은 `synthesisCards`, 옛 작업은 `labWorkspace`·`workDraft`. **서로 읽지 않는다** |

## 옛 작업을 카드로 가져오기 — 아직 없다

지시의 "저장된 대본·배역·목소리·구간과 접근 가능한 기존 결과를 카드로 가져오는 전환 경로"는
**만들지 않았다.** 지금은 두 체계가 서로의 저장본을 읽지도 쓰지도 않는다.

가져오기를 만들 때 지킬 것(지시 그대로):
- 읽기 실패·취소에서는 **원래 저장본을 보존한다.**
- 정보가 부족한 값을 임의로 채우지 않는다(예: 배역별 감정, 참조 목표 길이).
- 화면 제거와 저장본 삭제를 혼동하지 않는다.

## 옛 버전 탭을 뺄 수 있는 조건

위 표에서 **미연결** 이 하나라도 남아 있으면 뺄 수 없다. 특히
대본 통째 입력·배역 묶음·감정은 카드에 대응이 없다.
