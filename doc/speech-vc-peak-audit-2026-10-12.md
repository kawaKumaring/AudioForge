# 말하기 변환 최대 진폭 원인 분리

사용자 판정: 말하기용이 좀 더 기계음이 적긴 했다. 감정·발음·참조 유사도 합격으로 확대하지 않는다.

## 직접 확인

참조 A 분노를 같은 설정·seed로 생성하고 BigVGAN의 마지막 conv_post 이후, clamp 이전 신호를 확보했다. use_tanh_at_final=false인 현재 모델의 기존 forward는 ±1.0 잘라내기를 수행한다. soundfile FLOAT 저장은 이 원인이 아니다.

원시 최대 진폭 1.12606263. 전체 273,408개 중 21개(0.00768083%)가 ±1을 넘는다. 이 신호를 기존대로 잘라낸 결과는 앞선 말하기용 음성과 표본 단위로 완전히 같다(최대 오차 0). 따라서 해당 결과의 최대 진폭 1.0 원인은 모델 출력 후 내부 clamp임을 직접 확인했다.

이는 잘라내기 왜곡의 존재를 확인한 것이며 전체 기계음의 원인 확정은 아니다. 영향을 받은 표본은 매우 적고, 지각 영향은 위치와 주변 소리에 따라 달라진다. 음색 변환 자체의 손상·발화와 참조 차이는 별개로 남는다.

## 개선 비교

같은 실행의 두 신호(잘라낸 신호 / 잘라내지 않은 신호)에 동일 배율 0.8436475675를 적용했다. 잘라내지 않은 비교본의 최대 진폭은 0.95. 기존 출력·원음·참조는 보존했다. 이미 잘린 파일의 음량을 낮추는 복구가 아니라, 잘리기 전 신호의 형태를 보존하는 비교다.

BigVGAN.forward에 clip_output 선택 인자만 추가했다. 기본은 True이므로 기존 노래·말하기 호출은 그대로다. False는 이 원인 분리 실험에서만 사용하며, 원시 신호를 그대로 앱 재생에 넘기면 안 된다. tanh 모델에는 영향을 주지 않는다. 제품 기본 처리 변경은 청취 후 결정한다.
