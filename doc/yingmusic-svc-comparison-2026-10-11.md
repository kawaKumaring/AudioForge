## 연결

python/yingmusic_vc에 전용 추론 코드 추가. 공통 모델 4종과 공통 음향 코드는 기존 song_vc 재사용.
AF_SONG_VC_ENGINE=yingmusic으로 song_voice 변환 경계에서 선택 가능. 기본값은 기존 엔진.
GUI 선택이나 master 배포는 하지 않았다. 자동 음높이와 속도 변경을 거절하는 비교용 경로다.
사슬이 명시적 조옮김을 요청하면 현재 경로는 거절한다. 사슬 전체·실제 앱은 이번에 실행하지 않았다.
별도 반주 분리 모델·학습 자료·패키지는 설치하지 않았다.
공식 코드의 학습용 의존, 쓰지 않는 시각화와 매 단계 텐서 보관은 제거했다.
모델 로딩은 strict=True로 모든 가중치 확인, 임의 누락 허용하지 않음.

## 비교

승인된 원곡 45~65초와 참조 A의 기존 8초 조각. 기존 출력은 이전 실험 파일을 그대로 재사용.
seed 20261011, 40단계, CFG 0.7, fp16, 조옮김 0, 길이 배율 1.0, 후처리 없음.
새 결과 1개 생성 성공. 같은 seed라도 모델·구조가 달라 난수 연산 자체가 같다는 뜻은 아니다.
공식 예시의 100단계 대신 기존 비교와 맞춘 40단계 사용. 다른 단계의 우열은 미확인.

ECAPA 평균 참조 유사도: 기존 0.565/0.398, 새 모델 0.551/0.390 (기존 참조/다른 구간 참조).
음높이 비교의 공동 유성 구간에서 50센트 이내 비율: 기존 91.99%, 새 모델 92.83%.
양쪽 중앙 음높이 오차 10센트. 공동 유성 프레임 1074, 원본 유성 프레임 1094.
단일 화자·단일 20초·단일 seed, 말소리용 임베딩과 같은 시간대 pyin 추정이다.
목소리 닮음 개선은 수치로 확인하지 못함. 가락·가사·자연스러움 청취 합격을 뜻하지 않음.
