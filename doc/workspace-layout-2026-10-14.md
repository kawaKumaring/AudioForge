# 작업실 배치와 개발 상태

## 사용 흐름

왼쪽 메뉴 항목을 끌어 순서를 바꾸거나 두 분류 사이에 옮긴다. 배치 편집을 누르면 위·아래 이동 버튼과 분류 끝의 놓을 자리가 나타난다. 빈 분류도 옮길 수 있다. 파일에서 시작에 놓으면 개발 중 표시가 사라지고 새 콘텐츠 만들기에 놓으면 나타난다. 이 표시는 사용자의 배치 판단이며 자동 품질 합격 판정은 아니다.

메뉴 항목만 이동한다. 실제 파일과 모델 위치, 열린 작업의 입력은 바꾸지 않는다. 실험실과 내부 대화 재조립 모드는 기존처럼 노출하지 않는다.

## 구조와 예외

배치와 개발 상태는 workspaceLayout 공통 규칙을 사용한다. 기존 메뉴의 고정 분류와 노래 변환만 개발 중으로 표시하던 분기를 제거했다. 공유 구독 저장소를 통해 메뉴와 머리의 라벨이 같은 상태를 읽는다. 배치 저장은 전용 본체 통로에서 기존 원자적 설정 쓰기를 사용한다. 저장 성공 후에만 배치를 확정한다. 생성·취소 정리 중, 설정 읽기 실패, 저장 중에는 배치 변경을 막는다. 중복·누락·숨은 항목·잘못된 버전은 본체에서 거절한다. 읽기 실패나 설정 손상은 빈 배치로 덮지 않는다.

앱 시작의 콘솔 연결도 수명을 정리했다. 화면 종료 후 늦게 돌아온 연결은 즉시 해제하고, 초기화 실패가 미처리 예외로 남지 않게 했다. 생성 엔진과 음성 처리의 최적화는 이번 범위에 없다.

## 검증

공통 규칙 단위 7건, 실제 앱 MCP 16건 통과. 실제 마우스 드래그, 메뉴 이동 뒤 현재 작업 유지, 설정 파일 저장, 설정 손상 시 쓰기 거절과 배치 유지, 복구 후 재시도, 생성 중 이동 차단, 렌더러 재로딩 후 복원, 라벨 왕복, 좁은 창 가로 넘침 없음, 화면 오류 0건을 확인했다. 시험 자료는 격리한 앱 설정뿐이고 음성은 생성하지 않았다.

검사 초기에 선택자 공백·표현식 문법·화면 새로고침 방법이 잘못된 검사 코드를 수정했다. 마지막 실행은 모두 통과했다. 완전한 프로세스 종료·재시작은 이번에 따로 돌리지 않았다. 설정 파일의 저장과 새 렌더러 복원을 확인했다. 타입 검사 두 종류·빌드 통과. 전체 검사는 하지 않았다.
