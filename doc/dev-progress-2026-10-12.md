# 2026-10-12 개발 기록·커밋 운영

사용자 지시에 따라 완료한 작업 묶음마다 문서화, 파일을 지정한 커밋, develop 원격 푸시를 함께 진행한다. master 반영은 검수 상태와 배포 범위를 구분해 진행한다.

이번 묶음: 말하기용 Seed-VC 최소 추론 경로, 진폭 분석용 선택적 제한 해제, 기존 음성 CPU 분석, 단계별 중간 신호 기록, 관련 검사와 근거 문서. 모델·사용자 음성·청취 자료는 포함하지 않는다. 기존 노래 변환의 제한 처리 기본값은 유지한다.

검증 근거: 관련 검사 13건 통과. 초기 한 건은 검사 파일을 UTF-8로 읽지 않아 실패했고 검사 읽기를 수정한 뒤 통과했다. 실제 단계별 기록을 포함한 새 생성은 아직 하지 않았다. 기계음 원인은 미확정이며 생성은 마지막으로 미룬다.

이전 기호·문맥·감정·말끝 작업은 이번 독립 묶음에 섞지 않고 작업 트리에 보존한다. 보류된 연기 대본 편집기 4개 파일은 커밋하지 않는다. 전체 검사와 새로운 음성 생성은 반복하지 않는다.
