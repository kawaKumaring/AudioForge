## 1. 위치와 가지

- 개발: `E:\AI_Project\claudeCodeVsCode\apps\development\AudioForge_af_worktrees\develop-run` (가지 `develop`)
- 완성본: `E:\AI_Project\claudeCodeVsCode\apps\master\AudioForge` (가지 `master`) — 실제 모델 폴더 `externals` 가 여기 있다.

## 2. 반드시 지킬 사용자 규칙

- 한국어로만 쓴다. 답에 표를 쓰지 않는다.
- 결과를 보고하는 모든 턴에 관리자 보고서(복사용 코드 블록, 비개발자 용어, 숫자·한계·열린 항목)를 붙인다. 참조 목소리 인물은 A/B/C 로 쓴다.
- 외부 전송 금지. 앱은 오프라인으로 돈다.
- 사용자 음성·이미지·프롬프트 파일은 파일별 승인 후 연다.
- 화면 캡처·앱 실행·다운로드는 먼저 묻는다.
- 전체 검사(게이트) 금지 — 바꾼 곳에 닿는 검사만.
- ComfyUI 가 참조하는 모델은 지우지 않는다.
- 개발 모토는 흡수: 외부 도구를 통째로 부르지 말고 필요한 모델·코드만 앱 안으로.
- 사용자는 터미널을 쓰지 않는다.

## 3. 함정 (실제 사고)

- `externals` 는 작업 폴더에서 본체로 가는 정션. PowerShell `Remove-Item` 은 대상 안까지 지운다 → Node `fs.rmSync` 사용.
- 역슬래시 든 윈도우 경로를 셸 문자열로 넘기면 깨진다 → 스크립트 파일로 실행.
- 파이썬은 `PYTHONIOENCODING=utf-8`.
- 앱 본 파이썬 = ComfyUI 내장 `E:\AI\ComfyUI_windows_portable_python3.12\python_embeded\python.exe` (`externals/env.json`). torch·demucs·f5_tts·kokoro 가 여기. `externals/runtime/app-python` 은 torch 없는 단위 검사용, `gptsovits_venv_app` 은 GPT-SoVITS·노래 변환용.
- 검사 임시 폴더가 한글 경로(`_local\테스트\임시`)라 torch GPU 부품 캐시가 실패해 계산이 죽던 문제 → 검사에서만 `USE_PYTORCH_KERNEL_CACHE=0`(2026-10-11). `UnicodeDecodeError ... 0xc5` 가 보이면 이 계열, `e.object.decode('cp949')` 로 풀어 본다.
- 모델의 숨은 의존: F5-TTS 는 참조 대사가 비면 자체 받아쓰기를 인터넷에서 찾았다. 모델을 지우기 전에 라이브러리 안쪽까지 본다.
- 시험·도구 산출물은 모두 `master\AudioForge\_local\테스트` 아래(`doc/test-folder.md`).
